# Changelog

Все заметные изменения «Пульса». Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии — [SemVer](https://semver.org/lang/ru/).

## [0.3.0] — 2026-10-06

Pulse v2: финансы сходятся с картой, check-in сохраняется целиком, уведомления только в мессенджеры, новый дизайн.

### Финансы

- **Сверка с банком.** Экран «Финансы → Сверка»: баланс по Пульсу, баланс по карте (из последней выписки или введённый вручную), разница и список операций, которые её объясняют: разрывы цепочки остатков банка, операции выписки, которых нет в Пульсе, и ручные записи вне выписки.
- **Импорт по ID операции банка.** Колонки `Transaction ID`, `Time`, `Balance` распознаются; ID банка — ключ от повторного импорта. Повторная загрузка той же выписки дополняет старые записи ID, временем и остатком, не создавая дублей.
- **Деньги без float.** Суммы в статистике, бюджетах, общем балансе, импорте и AI считаются в копейках/Decimal — больше никаких «3198,4999».
- **Уведомление о расхождении** после импорта, если разница со счётом банка не объясняется операциями.

### Check-in

- **Полная запись из Telegram.** Раньше бот сохранял только настроение. Теперь check-in пошаговый: настроение → энергия → стресс → сон → теги → заметка, любой шаг можно пропустить. Быстрые формы: `/checkin 4 энергия 3 стресс 2 сон 7.5 #спорт заметка` и `/mood 4`.
- В истории, на дашборде дня и в статистике видны энергия, стресс и сон (средние за день).
- **Цель по check-in:** N отметок в неделю с прогрессом.
- **Корреляции:** «в дни с плохим сном ты тратишь на X% больше» — по сну, энергии и настроению за 60 дней.

### Уведомления

- **Уведомления v2.** Web push и ключи VAPID удалены; каналы — Telegram и Discord. Правила с каналом `web_push` при обновлении переводятся на `telegram`. Таблица `push_subscriptions` удалена.
- **Discord-бот** (`DISCORD_BOT_TOKEN`, `DISCORD_APPLICATION_ID`): привязка одноразовым кодом (`/link КОД` в личных сообщениях или slash-команда), доставка личными сообщениями.
- **Надёжная доставка:** очередь `notification_deliveries`, повторы с экспоненциальной паузой (до 5 попыток), остановка при блокировке бота; журнал последних 20 отправок в настройках и метрики для администратора.
- Настройки по каналам: включение, расписание, тихие часы, часовой пояс, типы. Новые типы: итог дня, расхождение баланса; предупреждения бюджета на 80% и при превышении.
- HTTPS через Tailscale стал необязательным — для уведомлений он больше не нужен.
- Браузер больше не запрашивает разрешение на уведомления; HTTPS через Tailscale стал необязательным.
- **Команды бота:** `/spent 12 кофе` — трата с автокатегорией и остатком бюджета; меню команд регистрируется в Telegram. Предупреждения бюджета работают и для импортированных трат.

### Дизайн

- **Новый стиль «пульс-монитор»:** мятная «миллиметровка», бирюзовый бренд, лайм для денег и янтарь для самочувствия, ночной монитор в тёмной теме; шрифты Unbounded и Onest; карточки со срезанным углом, кнопки-«клавиши».
- Зоны нажатия от 44 px, заметный фокус, анимации отключаются при `prefers-reduced-motion`. Lighthouse accessibility — 100 на ключевых страницах.
- Check-in — одно касание с главной, трата — три действия, итог дня виден сразу.

### Прочее

- **Приватная ссылка «Итог дня»** `/d/…` — итоги сегодняшнего дня без входа; ссылку можно перевыпустить или отозвать в настройках.
- **Откат миграций:** `down.sql` для всех миграций v2 и `scripts/migrate-rollback.sh` (сначала бэкап).
- **Логи и метрики:** ID запроса в каждом ответе (`X-Request-Id`), ошибки сервера в JSON, страница метрик для администратора (доставка уведомлений, очередь, ошибки).
- Аудит функций: `docs/FEATURE-AUDIT-V2.md` (48 функций, 0 сломанных).

### Обновление с 0.2.0

```bash
cd /opt/puls && sudo bash scripts/upgrade.sh
```

Уведомления после обновления приходят только в привязанные мессенджеры: привяжите Telegram или Discord в «Настройки → Уведомления». Переменные `VAPID_*` можно удалить из `.env`.

## [0.2.0] — 2026-10-02

### Добавлено

- **AI-помощник: больше провайдеров.** Кроме Anthropic, OpenAI, OpenRouter и своего адреса (Ollama, LM Studio) — OpenCode Go (подписка), OpenCode Zen, Google Gemini, DeepSeek, Mistral, Groq и xAI Grok. Достаточно вставить ключ: адрес и модель по умолчанию подставляются сами, под списком — подсказка, где взять ключ. Кнопка «Загрузить модели» показывает модели провайдера.
- **«Удалить все» операции** на экране «Финансы» — с подтверждением; балансы счетов возвращаются к значению без операций, счета и категории остаются. Удобно, чтобы заново загрузить выписку.
- **Раздел «AI» всегда в меню.** Без ключа на странице сразу форма подключения; после сохранения ключа открывается чат.
- **Кнопка «Настройки» в шапке** — на невысоких экранах пункт внизу бокового меню уходил за край.
- **HTTPS через Tailscale для push-уведомлений.** Одна установка работает одновременно по `http://` в локальной сети и по `https://имя.tailnet.ts.net`: два новых порта Caddy только на `127.0.0.1`, `COOKIE_SECURE=auto`, `EXTRA_ORIGINS`, `EXTRA_SANDBOX_ORIGINS`, API на том же адресе (`PUBLIC_API_URL=/`).
- **Telegram-бот без публичного адреса**: режим polling по умолчанию в `docker-compose.yml`.
- **`scripts/users.sh`** — профили, сброс пароля, роли и режим регистрации из консоли сервера.
- Гайд для новичков: разделы про push через Tailscale и уведомления в Telegram, таблица AI-провайдеров.

### Исправлено

- **Импорт выписки считал неправильно.** Одинаковые строки в одном файле (две поездки по 24 kr за день) считались дублями, и вторая отбрасывалась. Теперь это разные операции; повторный импорт того же файла по-прежнему ничего не дублирует. Чтобы дозагрузить пропущенное, импортируйте ту же выписку ещё раз.
- **Импортированные траты в статистике, бюджетах и AI были нулевыми** — не заполнялась сумма в базовой валюте. Исправлено, уже загруженные операции пересчитываются миграцией при обновлении.
- **Экран «Статистика» падал с ошибкой** при большом числе операций: параллельный пересчёт кеша взаимно блокировался в базе. Удалённые операции больше не остаются в статистике.
- **AI-помощник подписывал суммы чужой валютой** (₽ при счёте в кронах) — теперь знает базовую валюту пользователя.
- Тесты ленты подсказок больше не зависят от времени запуска.

### Обновление с 0.1.0

```bash
cd /opt/puls
sudo sed -i 's|^PUBLIC_API_URL=.*|PUBLIC_API_URL=/|' .env   # API на том же адресе, что и сайт
sudo bash scripts/upgrade.sh
```

Остальные новые переменные необязательны — см. «Настройка» в документации.

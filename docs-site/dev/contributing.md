# Как внести вклад

Спасибо за интерес к проекту! Мы рады баг-репортам, документации и коду.
Обзор для разработчиков — в разделе [Разработчикам](/dev/).

## Кодекс поведения

Участвуя в проекте, вы соглашаетесь с `CODE_OF_CONDUCT.md`.

## Лицензия вклада

Проект распространяется по **AGPL-3.0-or-later**. Отправляя pull request, вы
соглашаетесь на распространение своего вклада под этой же лицензией
(**inbound = outbound**, без отдельного CLA).

## Окружение

- Node.js ≥ 20, pnpm 11 (`corepack enable`)
- Docker с Compose для PostgreSQL 16 и Valkey 8

```bash
pnpm install
cp .env.example .env
pnpm docker:dev:up
pnpm db:migrate
```

## Перед отправкой PR

Прогоните локально ровно то, что проверяет CI:

```bash
pnpm lint
pnpm typecheck
pnpm test
pnpm build
pnpm format:check
pnpm license:check
```

- Если вы меняли схему Prisma — приложите миграцию
  (`pnpm db:migrate --name <что-изменилось>`).
- Если меняли API — добавьте или обновите smoke-тест.

## Правила для кода

- **Лицензионный заголовок.** Каждый новый исходник начинается со строки
  `// SPDX-License-Identifier: AGPL-3.0-or-later` (в CSS — `/* ... */`).
- **Типы.** Строгий TypeScript; `any` — только с комментарием, объясняющим причину.
- **Общие схемы.** Валидация данных — Zod-схемы в `packages/shared`, не дублируйте
  их в приложениях.
- **Тесты.** Новая логика приходит с тестом. Багфикс — с тестом, который падал
  до фикса.
- **Доступность.** Интерфейс соответствует **WCAG 2.1 AA**: контраст, управление
  с клавиатуры, подписи для скринридеров.
- **Тексты интерфейса.** Все строки — только через `t()` в `apps/web/src/lib/i18n.ts`,
  добавляйте **оба** языка (ru и en). Без обвинений и давления: «Записал!
  Хорошего вечера», а не «Вы превысили бюджет».

## Коммиты и PR

- Атомарные коммиты с внятным сообщением в императиве:
  `feat(api): добавлен эндпоинт /health`,
  `fix(web): тёмная тема не применялась к карточкам`.
- Один PR — одна тема. Описание: что изменилось, зачем, как проверить.
- AI-помощник и всё, что касается
  чувствительных данных, требуют особенно внимательного ревью.

## Политика лицензий зависимостей

Допустимы только лицензии, совместимые с AGPL-3.0-or-later: **MIT** (и MIT-0),
**Apache-2.0**, **BSD** (2/3-Clause), **ISC**, **0BSD**, **PostgreSQL**,
**MPL-2.0**, **OFL-1.1**, а также GPL/AGPL-совместимые. Проприетарные — нельзя.
Проверяет `pnpm license:check` (`scripts/check-licenses.mjs`) в CI на каждом PR.

## Безопасность

Не открывайте публичный issue для уязвимости — порядок ответственного раскрытия
описан в `SECURITY.md` и на странице [Безопасность](/security/).

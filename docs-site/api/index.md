# Открытый API и вебхуки

::: warning Раздел в разработке (Фаза 4)
Открытый API и вебхуки реализуются в **Фазе 4** (блок E) и пока недоступны в
стабильной сборке. Ниже — планируемое поведение по требованиям ТЗ (§4). Конкретный
список эндпоинтов, полей и форматов — по мере готовности — появится в файле
`docs/PHASE4-API.md` репозитория; на момент написания этой страницы он ещё не создан.
:::

Открытый API и вебхуки позволяют встроить «Пульс» в свою домашнюю автоматизацию:
**Home Assistant**, **n8n** или собственные скрипты. Как и всё в «Пульсе», это
работает на вашем сервере, без обязательных облачных сервисов.

## Токены

Доступ к API выдаётся по **токенам**, которые пользователь создаёт в настройках.
Токен можно отозвать в любой момент; он не заменяет пароль и не даёт доступа к
аккаунту целиком. Действия по токену выполняются от имени создавшего его
пользователя и **ограничены его данными**.

## Эндпоинты (общего вида)

API повторяет функциональные области самого «Пульса» — финансы, чек-ины, цели,
статистику — и работает по HTTPS за реверс-прокси Caddy (базовый префикс `/api/`).
Точные пути, методы и схемы запросов/ответов — в `docs/PHASE4-API.md`.

::: info Не выдумывайте пути
На этой странице не приводятся конкретные имена эндпоинтов и полей: они ещё
проектируются. Ориентируйтесь на файл `docs/PHASE4-API.md`, когда он появится.
:::

## Вебхуки

Вебхуки отправляют события «Пульса» на ваш внешний адрес (например, в Home Assistant
или n8n). Каждый вебхук настроен на свой адрес и свой **секрет**; запросы
**подписываются** этим секретом, чтобы получатель мог проверить, что событие
действительно пришло от вашего экземпляра и не было подделано.

::: warning Сетевой доступ
Переменная окружения `WEBHOOKS_ALLOW_PRIVATE` разрешает вебхуки на **приватные
адреса** (внутри вашей сети). Это нужно, когда получатель — устройство или сервис
локальной сети. Без неё вебхуки на приватные адреса заблокированы: это защита от
использования вебхуков для доступа к внутренним ресурсам сервера. Включайте
осознанно.
:::

## Примеры интеграций

- **Home Assistant.** Автоматизации по событиям «Пульса»: например, показать итог
  дня или напомнить о цели.
- **n8n.** Сценарии «Пульс → другое приложение»: собрать данные и передать в таблицу,
  мессенджер или другой сервис.

Точные форматы запросов и примеры — в `docs/PHASE4-API.md` по мере готовности.

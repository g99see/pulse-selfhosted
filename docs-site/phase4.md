# План Фазы 4 и статус блоков A–E

**Фаза 4** — четвёртый релиз «Пульса» (ТЗ §3.9 и §4). В неё входят AI-помощник по
API-ключу, семейный режим, открытый API и вебхуки, а также эта документация
(VitePress). Работа ведётся независимыми блоками, каждый — свой Nest-модуль.

::: warning Статус: в работе
Фаза 4 ещё не завершена. Блоки разрабатываются параллельно, а их технические
описания `docs/PHASE4-*.md` появляются по мере готовности (первым создан
`docs/PHASE4-AI-UI.md`, блок C). Ниже — планируемый состав работ.
:::

## Блоки

| Блок | Тема | Что входит | Техдокумент |
| --- | --- | --- | --- |
| **A** | AI backend | Адаптер провайдеров (Anthropic, OpenAI, OpenRouter, OpenAI-совместимые, Ollama/LM Studio), шифрование ключей AES-256-GCM (`APP_ENCRYPTION_KEY`), общий и личный ключи, лимиты и учёт токенов | `docs/PHASE4-AI.md` |
| **B** | AI чат и инструменты | Чат о своих данных, function calling **только на чтение** и **только текущего пользователя**, действия по подтверждению («Применить»), разборы недели/месяца | `docs/PHASE4-AI-CHAT.md` |
| **C** | AI интерфейс | Экраны настройки и подключения ключа, «Проверить подключение», показ отправляемых данных, учёт расхода в админке | `docs/PHASE4-AI-UI.md` |
| **D** | Семейный режим | Общие счета и цели семьи, приватный дневник у каждого, режимы экземпляра (один пользователь / семья по приглашениям / открытая регистрация) | `docs/PHASE4-FAMILY.md` |
| **E** | Открытый API и вебхуки | Токены, эндпоинты по областям, подпись вебхуков, `WEBHOOKS_ALLOW_PRIVATE` | `docs/PHASE4-API.md` |

## Пользовательская документация

- [AI-помощник](/ai/) — провайдеры, ключи, приватность, локальные модели.
- [Семейный режим](/family/) — общие счета и цели, режимы экземпляра.
- [Открытый API и вебхуки](/api/) — токены, подпись, интеграции.

## Как следить за прогрессом

По мере готовности блоков технические описания появятся в репозитории в файлах
`docs/PHASE4-AI.md`, `docs/PHASE4-AI-CHAT.md`, `docs/PHASE4-AI-UI.md`,
`docs/PHASE4-FAMILY.md` и `docs/PHASE4-API.md`. Пользовательские страницы,
на которые вы читаете, ссылаются на них.

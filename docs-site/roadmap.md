# Что нового и дорожная карта

Страница о текущем статусе «Пульса»: что уже работает, что появилось в последних
фазах и чего в сервисе пока **нет** — без обещаний и «в разработке».

## Статус по фазам

| Фаза | Тема | Статус |
| --- | --- | --- |
| **Фаза 1** | MVP: регистрация/вход, финансы, чек-ины, статистика, уведомления, экспорт/удаление, Docker + Caddy | ✅ реализовано |
| **Фаза 2** | Цели, регулярные платежи, импорт CSV, мультивалютность, рекомендации, стрики и достижения, вход по логину и паролю, Google, Telegram-бот | ✅ реализовано |
| **Фаза 3** | Публичный профиль, соцсеть, HTML-страница, модерация, шаринг — **удалены в ТЗ №2 §3** | 🗑 удалено |
| **Фаза 4** | AI-помощник, открытый API и вебхуки, документация VitePress | ✅ реализовано |
| **Фаза 5** | Привычки, капсула времени, «Год в цифрах», режим «Тишина», голосовой чек-ин (челленджи и виджет цели удалены в ТЗ №2) | ✅ реализовано |

## Что появилось в Фазе 4

- **AI-помощник** по своему API-ключу: провайдеры Anthropic, OpenAI, OpenRouter и
  любой OpenAI-совместимый (Ollama, LM Studio). Два уровня ключа, шифрование
  AES-256-GCM, чат с чтением данных текущего пользователя, предложения по кнопке
  «Применить», разборы недели/месяца с предпросмотром отправляемых данных, учёт
  токенов. Без ключа AI полностью скрыт. Подробнее: [AI-помощник](/ai/).
- **Открытый API и вебхуки**: личные токены `puls_…` (в базе только хеш, области
  `read`/`write`), `/api/v1/*`, вебхуки с HMAC-подписью, ретраями до 5 раз и
  защитой от SSRF. Подробнее: [Открытый API и вебхуки](/api/).

## Что появилось в Фазе 5

- [**Привычки**](/guide/usage/habits) — ежедневные и еженедельные трекеры с
  отметками прямо из чек-ина, сериями и статистикой.
- [**Капсула времени**](/guide/usage/capsules) — письмо себе со снимком данных,
  открывающееся через заданный срок.
- [**«Год в цифрах»**](/guide/usage/wrapped) — годовая сводка по деньгам,
  настроению, целям и достижениям.
- [**Режим «Тишина»**](/guide/usage/quiet-mode) — мгновенно скрывает денежные
  суммы (горячая клавиша **Alt+Q**).
- [**Голосовой чек-ин**](/guide/usage/voice-checkin) — диктовка заметки и итога
  дня; **аудио не покидает браузер**, на сервер уходит только распознанный текст.

## Чего в «Пульсе» пока нет

Честный список — этих возможностей в сервисе нет:

- **Федерация (ActivityPub)** — «Пульс» не связан с другими соцсетями и не
  поддерживает федеративные протоколы.
- **Плагины и расширения** — сторонних плагинов и API для их установки нет.
- **Интеграции здоровья** — нет синхронизации с Google Fit, Apple Health и
  трекерами; данные вводятся вручную (или через чекины/Telegram/API).
- **Скан чека** — распознавания фото чека нет.
- **Социальные функции** — друзей, подписок, ленты, публичных профилей, семейного режима и челленджей нет (удалены в ТЗ №2 §3).
- **Установка как приложение (PWA)** — нет (удалено в ТЗ №2 §5).

## Оговорки по проверке

Чтобы не выдавать желаемое за проверенное:

- Реальные вызовы облачных AI-провайдеров не проверялись — тесты идут на
  подменённом HTTP-клиенте.
- Lighthouse и «чистая установка `docker compose up -d`» не перегонялись после
  Фаз 2–5.
- Сервис `ollama` в compose — закомментированный пример.

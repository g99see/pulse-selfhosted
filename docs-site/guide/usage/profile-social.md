# Профиль и лента

Публичный профиль — это ваша страница с аватаром, обложкой, коротким описанием
и набором карточек, которыми вы делитесь. Вокруг него работает лента подписок с
реакциями и комментариями (ТЗ §3.7).

## Адрес профиля

Страница доступна по короткому адресу `ваш-домен/@nickname` и по внутреннему
адресу `ваш-домен/u/[nickname]`. Символ `@` зарезервирован Next.js за parallel
routes, поэтому короткий адрес отдаётся rewrite-правилом на `/u/:nickname` —
это одна и та же страница.

- Профиль с приватностью `private` отдаёт `404` — факт его существования не
  раскрывается.
- Приватность самого профиля управляется полем `User.profileVisibility`.

## Карточки и их приватность

Набор карточек фиксирован: по одной каждого типа на пользователя.

| Тип карточки | Что показывает |
| --- | --- |
| `savings` | Прогресс накоплений |
| `checkin_streak` | Стрик чек-инов |
| `avg_mood` | Среднее настроение за месяц |
| `achievements` | Достижения |
| `goals` | Цели |
| `html_page` | Ссылка на HTML-страницу профиля |

У каждой карточки — своя приватность:

| Видимость | Кто видит |
| --- | --- |
| `public` | Все, включая анонимных гостей |
| `subscribers` | Только подписчики и владелец |
| `private` | Только владелец |

По умолчанию карточки **скрыты** (`private`). Карточки `private` не отдаются
никому, `subscribers` — только подписчику и владельцу.

У карточки есть режим отображения: `percent` или `amount` (по умолчанию —
`percent`). Сумма осмысленна только для `savings` и `goals`; у остальных режим
схлопывается в проценты. **Суммы по умолчанию скрыты** — показываются проценты.

Редактор профиля находится на `/app/profile`: там задаются описание, ссылки на
аватар и обложку, а также приватность и режим каждой карточки.

## Подписки

Подписки — направленный граф «кто на кого подписан».

- `POST /api/follows/:nickname` — подписаться (на себя нельзя → `400
  cannot_follow_self`; неизвестный ник → `404`).
- `DELETE /api/follows/:nickname` — отписаться.
- `GET /api/follows/followers` и `GET /api/follows/following` — списки подписок.
- `GET /api/follows/:nickname` — состояние подписки.

Повторная подписка идемпотентна.

## Лента

Лента (`/feed`) показывает посты ваших подписок и ваши собственные. Посты
создаются автоматически при получении достижения, создании цели и пересечении
вех прогресса цели (25 / 50 / 75 / 100 %). В посте хранится компактный payload —
код бейджа, id и название цели, процент; **суммы в ленте не публикуются**.

Пагинация — по курсору:

```
GET /api/feed?cursor=&limit=20
```

(`limit` — от 1 до 50, по умолчанию 20). Невидимые для вас посты отбрасываются.

### Приватность постов

Видимость поста (`public | subscribers | private`) ограничена приватностью
профиля владельца: итоговая видимость — строжайшая из двух. Приватный профиль не
отдаёт посты даже подписчикам.

## Реакции и комментарии

- **Реакции** — фиксированный набор эмодзи: 👍 🔥 🎉 💪 ❤️. Повторное нажатие
  снимает реакцию. `POST /api/posts/:postId/reactions` идемпотентен,
  `DELETE /api/posts/:postId/reactions/:emoji` — снять.
- **Комментарии** — не длиннее 500 символов. Удалить может автор комментария или
  владелец поста. На добавление действует лимит 20 в минуту.
- На реакцию или комментарий владельцу поста приходит уведомление, если общий
  переключатель уведомлений включён.

## Поделиться результатом

Кнопка **«Поделиться результатом»** генерирует картинку-карточку для Instagram и
Telegram. Доступны типы: прогресс цели, стрик чек-инов, достижение и среднее
настроение; форматы — `story` (1080×1920) и `square` (1080×1080).

- `GET /api/share/card?...` — SVG, `GET /api/share/card.png?...` — PNG.
- По умолчанию показываются **проценты**; суммы включаются явно
  (`amounts=1` в запросе).
- Карточка всегда строится только из ваших данных: чужая цель → `404`, без
  сессии → `401`.
- В интерфейсе кнопка делится через Web Share API, с запасными вариантами
  «Скачать PNG» и «Открыть в Telegram».

## Жалобы

На профиль и контент можно пожаловаться (кнопка «Жалоба» рядом с целью). Жалобы
попадают в очередь модерации. На собственный профиль пожаловаться нельзя;
повторная жалоба на ту же цель, пока она открыта, блокируется; действует лимит
10 жалоб в час. Подробнее — в разделе [Администрирование](/admin/).

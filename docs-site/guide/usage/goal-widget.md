# Виджет цели

Виджет цели — публичный встраиваемый прогресс-бар цели для блога или портфолио:
вставка через `<iframe>` на страницу, которую владелец размещает у себя.
Реализация — ТЗ §4 (P3). Виджет отдаёт **только проценты и вехи**, суммы по
умолчанию скрыты.

## Публичный API

`GET /api/public/widgets/goal/:goalId` — без сессии и без cookie.

| Условие | Ответ |
| --- | --- |
| Цель `visibility=public` и профиль владельца `public` | 200, `{ widget: GoalWidgetDto }` |
| Приватная или `subscribers`-цель | 404 `goal_not_found` |
| Публичная цель при закрытом профиле владельца | 404 `goal_not_found` |
| Несуществующий id | 404 `goal_not_found` |

- Проверка видимости — `canViewProfile(profileVisibility)` для анонимного
  смотрящего: уровень `public` (ТЗ §3.7).
- Заголовки: `Access-Control-Allow-Origin: *`, `Access-Control-Allow-Methods: GET`
  (CORS только на чтение), `Cache-Control: public, max-age=60` (кэш 60 с).
- Суммы в ответе отсутствуют — только `percent`, `milestones`, `title`, `image`,
  `deadline`, `nickname`.

## Страница для iframe

`/widget/goal/[goalId]` (`apps/web/src/app/widget/goal/[goalId]/page.tsx`) —
минимальная страница **без AppShell**, адаптивная; светлая/тёмная тема следует
`prefers-color-scheme` (класс `.dark` ставит скрипт темы корневого layout). При
404 рисует заглушку «Виджет недоступен» и не индексируется (`robots: noindex`).
Данные берутся у публичного API на сервере (`SERVER_API_URL`).

## Кнопка «Встроить» в экране целей

На карточке цели кнопка «Встроить» раскрывает панель с готовым сниппетом:

```html
<iframe src="https://<домен>/widget/goal/<id>" width="360" height="150"
        style="border:0" loading="lazy" title="Прогресс цели"></iframe>
```

- Сниппет виден в поле только для чтения, рядом — кнопка «Скопировать код» и
  ссылка «Открыть виджет».
- Для непубличной цели вместо сниппета — подсказка сменить приватность на
  «Публично».
- Все строки интерфейса — через `i18n.ts` (ru/en).

## API

| Метод | Путь | Назначение |
| --- | --- | --- |
| GET | `/api/public/widgets/goal/:goalId` | Публичные проценты и вехи цели без сессии и cookie |

Ошибки — в едином формате `{ code, message }`: `goal_not_found`.

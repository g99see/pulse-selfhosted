# Голосовой чек-ин

Голосовой чек-ин позволяет надиктовать, как прошёл день: сервис расшифрует запись
и выделит теги. Реализация — ТЗ §4 (P2). Кнопка микрофона появляется у **заметки**
и у **итога дня** («Что сегодня получилось?») в расширенном чек-ине на экране
`app/(app)/checkin`.

## Приватность

::: info Распознавание идёт целиком в браузере
Речь распознаётся локально через Web Speech API (`SpeechRecognition` /
`webkitSpeechRecognition`), язык — по локали интерфейса (`ru-RU` / `en-US`).
**Аудио на сервер не уходит** — наружу летит только готовый текст, сохранённый в
поле заметки или итога дня. Сервер не получает ни записи, ни потоковой
расшифровки, ни ключей внешних распознавателей. Это принципиально для self-hosted
и приватности.
:::

## Извлечение тегов

Словарь «ключевое слово → тег» (ru/en) и функция `extractVoiceTags(text)` живут в
`packages/shared/src/voice-tags.ts`.

- Возвращает **уникальные канонические теги в порядке словаря**; теги совпадают с
  привычными тегами чек-инов: `работа`, `спорт`, `сон`, `еда`, `семья`, `друзья`,
  `учёба`, `здоровье`, `болею`, `ссора`.
- Ключевое слово ищется **с начала слова** (`(?<![\p{L}\p{N}])`), поэтому основа
  `тренир` ловит «тренировка»/«тренируюсь», а «сон» не срабатывает на «персон».
  Регистр и «ё/е» нормализуются.
- Схему чек-ина это не меняет: тег остаётся свободной строкой до 64 символов
  (`CheckInInputSchema.tags`). Новых таблиц и миграций нет.

## Поведение интерфейса

- Распознанный текст дописывается в соответствующее поле — заметку или итог дня.
- Найденные теги показываются **чипами в отдельном блоке** «Теги из записи».
- Тег добавляется в чек-ин только после нажатия пользователем (`aria-pressed`) —
  то есть **подтверждается вручную**.

## Поддержка браузера

Если Web Speech API нет, кнопка **не отображается**, а на её месте — подсказка с
пояснением про приватность (`checkin.voice.unsupported`, ru/en).

## API

Новых маршрутов нет: расшифрованный текст просто попадает в поля чек-ина, а теги
сохраняются существующим API чек-инов. Схема тегов не меняется — см.
[Чек-ины самочувствия](./checkins).

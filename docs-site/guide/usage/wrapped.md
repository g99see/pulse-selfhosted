# Год в цифрах

Сводка за календарный год по личным данным пользователя. Реализация — ТЗ §3.4.
Экран-«сторис» живёт на `/wrapped`. Изменений схемы БД нет: фича читает
существующие таблицы.

## Что показывает

- сколько потрачено и заработано, чистый итог (`net`);
- топ категорий, самый дорогой день, частый день недели;
- настроение по месяцам, лучший и худший месяц;
- самый длинный стрик чек-инов;
- число завершённых целей и полученных достижений.

## Эндпоинт

| Метод | Путь | Кто | Назначение |
| --- | --- | --- | --- |
| GET | `/api/wrapped` | владелец сессии (`SessionGuard`) | Сводка за год; параметр `year` необязателен |

Параметр `year` (1970…9999) необязателен: без него берётся текущий год в
часовом поясе пользователя (по `todayKeyInTimezone`). Некорректный год →
`400 { code: 'validation_error', message: 'Некорректный год' }`. Без сессии —
`401 unauthorized`.

## Таблицы-источники

| Данные | Таблица | Условие выборки |
| --- | --- | --- |
| Траты и доходы | `transactions` | `type in (expense, income)`, `date` в пределах года |
| Названия категорий | `categories` | по `categoryId` транзакций |
| Настроение | `check_ins` | `occurredAt` в границах года по часовому поясу |
| Завершённые цели | `goals` | `savedAmount >= targetAmount` и `updatedAt` в году |
| Достижения | `user_achievements` | `earnedAt` в году |

Переводы (`type = 'transfer'`) в расходы и доходы не попадают. Границы года для
денег — по дате `@db.Date` (UTC-полночь), для чек-инов — по локальному поясу
пользователя через `zonedDayBounds`.

Завершение цели приближено моментом последнего обновления (`updatedAt`): точной
даты закрытия модель `Goal` не хранит.

## Расчёты

Чистые функции `@puls/shared/src/wrapped.ts`:

| Функция | Что считает |
| --- | --- |
| `topCategories(transactions, limit = 3)` | Только расходы; группировка по `categoryId` (без категории — отдельный ключ), сортировка по сумме убыванию, затем по имени |
| `mostExpensiveDay(transactions)` | День с максимальной суммой расходов; при равенстве — ранний; без расходов — `null` |
| `mostFrequentWeekday(transactions)` | Частый день недели по числу расходных транзакций (`getUTCDay`, 1=Пн … 7=Вс); при равенстве — меньший |
| `moodByMonth(checkins)` | Среднее настроение по месяцам (один знак), по возрастанию ключа `YYYY-MM` |
| `bestWorstMoodMonths(months)` | Лучший/худший месяц по среднему; при равенстве — ранний; пусто → `{ best: null, worst: null }` |
| `bestStreakOf(checkins)` | Самый длинный стрик по уникальным дням (`computeStreak`) |
| `buildWrapped(input, { timezone, currency })` | Сборка ответа; переиспользует `sumSpent` / `sumEarned` / `roundMoney` и `moodAverage` |

## Пустой год

Если данных за выбранный год нет, ответ — нули и `null`: `spent` / `earned` /
`net` = 0, `topCategories` = `[]`, `mostExpensiveDay` / `mostFrequentWeekday` =
`null`, `avgMood` / `bestMonth` / `worstMonth` = `null`, остальные счётчики = 0.

## Экран `/wrapped`

Слайды: обложка → деньги → топ категорий → дни года → настроение → чек-ины →
цели и достижения. Листается кнопками и стрелками клавиатуры
(`←` / `→`); каждый слайд размечен `aria-roledescription` и подписью «Слайд N из
M», смена слайда анимируется и отключается при `prefers-reduced-motion`. Флаг
`isEmpty` показывает отдельный слайд «Пока пусто». Год переключается кнопками
«Раньше» / «Позже» (не дальше текущего).

- Клиент `lib/wrapped-client.ts` — `wrappedApi.year(year?)` через `authFetch`.
- Ссылки без пункта навигации: баннер на главной (`app/(app)/app/page.tsx`)
  виден с 1 декабря по 31 января; постоянная ссылка — на экране «Статистика»
  (`data-testid="stats-wrapped-link"`).
- Все строки — в `src/lib/i18n.ts` (ru/en).
- Режим «Тишина» применяется к суммам на экране.

## API

| Метод | Путь | Назначение |
| --- | --- | --- |
| GET | `/api/wrapped` | Сводка за год; `year` необязателен |

Ошибки — в едином формате `{ code, message }`: `validation_error` (год вне
диапазона 1970…9999), `unauthorized`.

# Привычки

Привычки — трекер ежедневных и еженедельных действий (вода, спорт, чтение) с
отметками из чек-ина и расчётом серии. Реализация — ТЗ §4 (P2, «Привычки: трекер
привычек … с отметками в чек-ине»). Экран живёт в `app/(app)/habits`.

## Экран `/habits`

- **Форма привычки**: название, иконка-пресет (эмодзи), частота и цель в неделю.
- **Список активных** с серией и процентами выполнения за 7/30 дней.
- **Архив** с возможностью вернуть привычку и удалить её.

Все строки интерфейса — в `src/lib/i18n.ts` (ru/en, одинаковые ключи).

## Блок «Привычки сегодня»

Компонент `components/habits-today.tsx` показывает привычки текущего дня с
чекбоксами. Он встроен на страницу чек-ина `/checkin` и в карточку чек-ина на
главной и обновляется по событию `puls:habits-changed`. Если привычек нет, блок
не показывается.

## Поля привычки

Модель `Habit` (ТЗ §7):

| Поле | Смысл |
| --- | --- |
| `name` | Название привычки |
| `icon` | Эмодзи-пресет (загрузки файлов нет) |
| `goal_type` | `daily` — каждый день / `weekly` — `per_week` раз в неделю |
| `per_week` | Число раз в неделю для `weekly`, 1–7 |
| `archived` | Признак архивации |

Модель `HabitLog`: `habit_id`, `user_id`, `date` (`@db.Date`), `done`.
Уникальна пара `(habit_id, date)`.

## Отметки и частота

Отметка идемпотентна: пара `(habit_id, date)` уникальна, повторный вызов за ту же
дату обновляет существующую запись, а не создаёт дубликат. Дата — календарный
день в часовом поясе пользователя (`users.timezone`); будущее отклоняется. Вызов
с `done=false` снимает отметку.

Серия и проценты считаются чистыми функциями `@puls/shared/src/habits.ts`:

| Функция | Что считает |
| --- | --- |
| `habitStreak(doneDayKeys, todayKey)` | Серия дней подряд; если сегодня ещё не отмечено, серия не считается прерванной до конца дня (отсчёт от вчера) |
| `habitCompletionRate(doneDayKeys, todayKey, windowDays, cadence, perWeek)` | Процент выполнения за 7/30 дней, 0..100: у `daily` ожидание — каждый день, у `weekly` — `per_week * windowDays / 7` |

Там же — `habitExpectedCompletions`, `habitDayKey`, `shiftDayKey`,
`habitDayToDate`, `habitDateToDayKey`, `habitStatsFromDayKeys` и Zod-схемы
`HabitCreateSchema`, `HabitUpdateSchema`, `HabitLogSchema`.

## API

Все маршруты — под `SessionGuard`, данные только текущего пользователя
(`/api/habits`):

| Метод | Путь | Назначение |
| --- | --- | --- |
| GET | `/` | Список привычек (активные, затем архив) |
| GET | `/:id` | Одна привычка |
| POST | `/` | Создание (название, иконка, частота) |
| PUT | `/:id` | Правка, в т.ч. архивация (`archived`) |
| DELETE | `/:id` | Удаление вместе с отметками |
| POST | `/:id/log` | Идемпотентная отметка за дату (`done=false` снимает) |
| GET | `/today` | Привычки текущего дня с отметкой и серией |
| GET | `/stats` | Серия и проценты за 7/30 дней по каждой привычке |

Ошибки — в едином формате `{ code, message }`: `validation_error`,
`habit_not_found`, `habit_future_date`, `unauthorized`.

## Изоляция данных

Каждый запрос фильтруется по `user_id` сессии: чужая привычка не видна и не
меняется (`404`). Закреплено интеграционным тестом «Изоляция данных между
пользователями». Достижение за серию привычки намеренно не добавлено.

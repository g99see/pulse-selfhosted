# HTML-страница и шаблоны

В профиль можно добавить свою HTML-страницу: написать код во встроенном
редакторе с предпросмотром или загрузить готовый `.html`-файл. Страница
показывается отдельной вкладкой профиля и по прямой ссылке
`ваш-домен/@nickname/page` (ТЗ §3.8).

::: danger Безопасность
HTML-страница — это **пользовательский контент**, который отдаётся с отдельного
домена в песочнице. Никогда не вводите пароли, платёжные данные и любые другие
секреты на чужой HTML-странице: она может быть создана для фишинга. Сервис
автоматически проверяет страницы, но гарантий против всех уловок нет.
:::

::: warning Лицензия
Собственный HTML-код, который вы загружаете или пишете, **не покрывается**
лицензией кода проекта (AGPL-3.0-or-later). Ответственность за его содержимое
лежит на вас.
:::

## Редактор `/page-editor`

Редактор открывается по адресу `/page-editor`. Раскладка — код слева,
предпросмотр справа; на мобильном это вкладки.

- **Предпросмотр** — `iframe srcdoc` с атрибутом `sandbox="allow-scripts"`,
  **без** `allow-same-origin`, и `referrerPolicy="no-referrer"`.
- **Загрузка файла** — один `.html`-файл до **2 МБ** (multipart, поле `file`).
- **Живой предпросмотр** дополнительно прогоняет код через автопроверку прямо в
  браузере.

## Готовые шаблоны

Для тех, кто не пишет код, есть четыре шаблона:

- **визитка**;
- **портфолио**;
- **вишлист**;
- **«моя цель»**.

Шаблон вставляется в редактор, после чего его можно доработать и сохранить.

## Публичная вкладка

Страница доступна как вкладка профиля и по прямой ссылке
`/@nickname/page` (внутренний маршрут — `/u/[nickname]/page`). В ней используется
iframe песочницы с теми же атрибутами изоляции, что и в редакторе.

Страница отдаётся с отдельного домена песочницы (`SANDBOX_DOMAIN`, например
`usercontent.ваш-домен`) и публикуется, только если одновременно:

- `published = true` и есть текущая версия;
- статус автопроверки текущей версии — не `blocked`;
- карточка `html_page` профиля видна публично (если карточки нет, решает флаг
  `published`; `private` и `subscribers` анонимно не отдаются);
- контент не скрыт модератором.

## Изоляция в песочнице

- Страница отдаётся с **отдельного домена** внутри `iframe` с
  `sandbox="allow-scripts"` и **без** `allow-same-origin`.
- Оба фрейма считаются чужим origin, поэтому чужие cookie и данные основного
  сайта недоступны. Скрипты страницы при этом работают.
- Caddy на домене песочницы проксирует только `/sandbox/*`, режет cookie в обе
  стороны и ставит CSP-подстраховку.
- Ответ сопровождается строгими заголовками:

```
Content-Type: text/html; charset=utf-8
Content-Security-Policy: default-src 'none'; script-src 'unsafe-inline';
  style-src 'unsafe-inline' https:; img-src https: data:;
  form-action 'none'; base-uri 'none'; frame-ancestors <основной домен>
X-Content-Type-Options: nosniff
Referrer-Policy: no-referrer
Cache-Control: no-store
```

## История версий

- Хранятся **последние 10 версий**; более старые вытесняются при сохранении.
- Сохранение, загрузка файла и откат каждый раз создают **новую версию** —
  история не переписывается.
- `GET /api/html-page/versions` отдаёт до 10 версий,
  `POST /api/html-page/versions/:id/restore` откатывает к выбранной.

## Автопроверка при сохранении

Каждое сохранение и загрузка проходят автопроверку. «Внешний» адрес — любой
хост, кроме домена песочницы; относительные пути свои. Итог: любой `blocked` →
`blocked`, иначе при наличии причин → `flagged`, иначе → `ok`.
**Заблокированная страница не публикуется**, даже если вы включили `published`.

| Причина | Статус | Что ловит |
| --- | --- | --- |
| `external_form_action` | blocked | `<form action>` на сторонний адрес |
| `password_form_external` | blocked | парольный ввод в форме на внешний хост |
| `meta_refresh` | blocked (с `url=`) / flagged | `<meta http-equiv="refresh">` |
| `auto_redirect` | blocked | `location =` / `location.replace/assign` в скрипте |
| `suspicious_link` | blocked | внешняя ссылка со словами «вход/пароль/банк» |
| `javascript_url` | flagged | ссылка `javascript:` |
| `external_script` | flagged | внешний `<script src>` (CSP его заблокирует) |
| `external_request` | flagged | `fetch`/XHR/`sendBeacon` на внешний адрес |
| `antivirus` | blocked | ClamAV нашёл сигнатуру |

После сохранения редактор показывает статус (`ok | blocked | flagged`) и список
причин: заблокированные — красным, помеченные — как предупреждения.

### Антивирус (ClamAV)

Проверка включается переменной `CLAMAV_HOST`:

- пусто (по умолчанию) — проверка отключена, в лог пишется понятное сообщение;
- `host:port` — подключение к clamd по протоколу INSTREAM.

## API

Все эндпоинты — под сессией.

| Метод | Путь | Назначение |
| --- | --- | --- |
| GET | `/api/html-page` | Текущая страница (`exists=false` — ещё нет) |
| PUT | `/api/html-page` | Сохранить код (`{ html, note?, published? }`) |
| POST | `/api/html-page/upload` | Загрузить `.html` (multipart, поле `file`) |
| GET | `/api/html-page/versions` | Последние 10 версий |
| POST | `/api/html-page/versions/:id/restore` | Откат к версии |
| DELETE | `/api/html-page` | Удалить страницу и историю |

Ошибки: `validation_error`, `invalid_file_type`, `file_required`, `413` (файл
больше 2 МБ), `version_not_found`, `unauthorized`.

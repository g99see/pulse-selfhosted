# Режим «Тишина»

Режим «Тишина» прячет все денежные суммы и балансы на экранах одним жестом —
удобно в общественном месте. Реализация — ТЗ §4 (P1). Это клиентский режим **без
бэкенда**: переключатель живёт в шапке `AppShell` и в разделе настроек, отдельных
серверных маршрутов у него нет.

## Состояние

| Место | Что хранится |
| --- | --- |
| `localStorage` | ключ `puls_quiet` (`'1'` — включён) |
| cookie `puls_quiet` | `SameSite=Lax`, срок 1 год — запасной источник, если `localStorage` недоступен (приватный режим) |
| атрибут `<html>` | `data-quiet="true"` — чтобы стили подстраховали рендер |

Логика вынесена в `lib/use-quiet-mode.ts`: `useQuietMode()` подписывается через
`useSyncExternalStore` на один модульный store на вкладку, поэтому переключение
видно всем компонентам; межвкладочные изменения ловит событие `storage`.
`setQuietMode` / `toggleQuietMode` меняют состояние, `quietModeValue()` — чтение
без подписки.

## Компоненты

| Компонент | Назначение |
| --- | --- |
| `Money` (`components/money.tsx`) | обёртка суммы: в тишине рисует маску `••••` (`MASKED_AMOUNT`), иначе `formatMoneyLocale` |
| `QuietModeToggle` | кнопка с `aria-pressed` и понятной подписью — в шапке `AppShell` и в настройках |
| `QuietModeHotkey` | монтируется один раз в `AppShell`: горячая клавиша и вежливый `aria-live`-регион |
| `QuietModeSection` (`components/quiet-mode-section.tsx`) | блок в настройках с пояснением |

Скрытая сумма помечена `aria-label` и `data-quiet-masked`. Для сумм внутри
составных строк экраны используют хук и `MASKED_AMOUNT` напрямую.

## Горячая клавиша

**Alt+Q** переключает режим из любого места кабинета. Смена состояния
объявляется скринридеру через `role="status"` + `aria-live="polite"`.

## Где скрываются суммы

Суммы маскируются на экранах: главная (дашборд дня `today-stats.tsx`),
статистика, финансы и регулярные платежи, цели, семья, рекомендации и «Год в
цифрах». **Поля ввода не маскируются** (например, предпросмотр быстрого ввода) —
пользователь видит то, что печатает.

## API

Серверных маршрутов у режима нет — он полностью клиентский. Состояние лишь
переживает перезагрузку за счёт `localStorage` и cookie.

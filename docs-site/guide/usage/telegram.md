# Telegram-бот

Бот «Пульса» позволяет записывать чек-ины и траты прямо из чата, не открывая
сайт. Он построен на [grammY](https://grammy.dev) (MIT). Без токена бота модуль
неактивен: в логах появляется предупреждение, а API работает как обычно.

## Подключение бота (для владельца инстанса)

Бот включается токеном от [@BotFather](https://t.me/BotFather). Переменные
описаны в разделе [Настройка (.env)](/guide/configuration):

| Переменная | Назначение | По умолчанию |
| --- | --- | --- |
| `TELEGRAM_BOT_TOKEN` | Токен бота от @BotFather. Без него бот выключен | — (пусто) |
| `TELEGRAM_BOT_USERNAME` | Имя общего бота для deep-link привязки (без `@`); иначе берётся из `getMe` | — (пусто) |
| `TELEGRAM_WEBHOOK_SECRET` | Секрет вебхука, сверяется с `X-Telegram-Bot-Api-Secret-Token` | — (пусто, вебхук отвечает `503`) |
| `TELEGRAM_MODE` | `webhook` (прод) или `polling` (разработка) | `webhook` |
| `TELEGRAM_API_FAKE` | `1` — клиент Telegram подменяется заглушкой (e2e, отладка) | — |

Владелец регистрирует вебхук у Telegram:

```
https://api.telegram.org/bot<TOKEN>/setWebhook?url=https://<домен>/api/telegram/webhook&secret_token=<TELEGRAM_WEBHOOK_SECRET>
```

## Режимы работы

- **webhook** (по умолчанию, для продакшена) — Telegram шлёт обновления на
  `POST /api/telegram/webhook`. Этот запрос не несёт cookie сессии, поэтому путь
  исключён из глобальной CSRF-защиты и защищён только секретным заголовком
  (сравнение — за постоянное время).
- **polling** (для разработки) — процесс API сам вызывает `getUpdates` и
  обрабатывает обновления. При недоступности Telegram цикл ждёт и повторяет; API
  не падает.

## Привязка аккаунта одной кнопкой

Общий бот Pulse на сервисе — пользователю не нужно создавать своего бота через
BotFather. Авторизация входа через Telegram удалена; бот остаётся **каналом
уведомлений**.

1. В настройках сайта (`/settings`), в секции «Telegram», нажмите
   **«Подключить Telegram»**.
2. Сервис создаёт одноразовый токен привязки (TTL 10 минут; не более 5 запросов
   за 10 минут на пользователя) и отдаёт deep-link
   `https://t.me/<bot>?start=<токен>`. В базе хранится только SHA-256 от токена.
3. Переход по ссылке открывает чат с ботом — нажмите **Start** (бот получит
   `/start <токен>`).
4. Чат привязывается к вашему аккаунту, токен гасится, включается канал
   уведомлений `checkins / telegram`, а экран настроек **сам** переключается на
   «Привязан» (опрос статуса каждые 3 секунды).
5. Отвязать чат можно кнопкой «Отвязать» в настройках либо командой `/unlink`.
   Повторное подключение — той же кнопкой.

Ошибки обрабатываются явно: просроченный токен, уже использованный токен,
чат, занятый другим аккаунтом. Один чат — один аккаунт, и у пользователя — один
чат. Если чужой `chat_id` пишет боту без привязки, он получает только подсказку
про привязку и ничего не пишет в базу.

## Команды бота

| Команда | Действие |
| --- | --- |
| `/start <токен>` | Привязка чата по ссылке из настроек |
| `/checkin` | Пошаговый чек-ин кнопками; `/checkin 4 энергия 3 сон 7.5` — одной строкой |
| `/mood 4` | Быстро записать настроение 1–5 |
| `/spent 12 кофе` | Записать расход: категория подбирается сама, в ответе — остаток бюджета категории |
| `кофе 250`, `зарплата +80000` | Быстрая транзакция на счёт по умолчанию |
| `/today` | Траты и среднее настроение за сегодня |
| `/unlink` | Отвязать чат |
| `/help` | Справка |

### Траты из чата

Просто отправьте сообщение вида `кофе 250` или `зарплата +80000` — бот запишет
транзакцию на счёт по умолчанию. Категория подбирается автоматически
(`guessCategoryName`). В ответ приходит «Записал! …» с кнопкой **«Отменить»**.

### Команда /spent

`/spent 12 кофе` (или `/spent кофе 12`) всегда создаёт **расход** на первом счёте
пользователя; знак `+`/`−` в аргументе игнорируется. В ответ приходит категория и,
если на неё стоит бюджет на месяц, — сколько осталось («Бюджет «Еда»: осталось
988 ₽ из 1 000 ₽») либо на сколько он превышен. Кнопка **«Отменить»** удаляет запись.
Меню команд регистрируется у Telegram при старте бота (`setMyCommands`): команды
видны по `/` в чате.

### Чек-ины из чата

`/checkin` показывает inline-кнопки настроения 1–5. Нажатие кнопки создаёт
чек-ин; ответ на уведомление о чек-ине приходит с теми же кнопками 1–5.

## Уведомления в Telegram

В список каналов уведомлений добавлен `telegram`. Если у типа `checkins` канал —
Telegram, сообщение уходит в привязанный чат с inline-кнопками 1–5. Если чат не
привязан, доставка просто не выполняется. Подробнее о правилах и расписании — в
разделе [Уведомления](./notifications).

## HTTP-точки

| Метод и путь | Защита | Назначение |
| --- | --- | --- |
| `POST /api/telegram/webhook` | заголовок `X-Telegram-Bot-Api-Secret-Token` | Приём обновлений |
| `GET /api/telegram/status` | сессия | Состояние привязки для настроек |
| `POST /api/telegram/connect` | сессия + CSRF + лимит частоты | Одноразовая ссылка-подключение |
| `DELETE /api/telegram/link` | сессия + CSRF | Отвязка |

## Изоляция Telegram API

Реальные запросы выполняет `GrammyTelegramApi`; ядро бота работает через
интерфейс `TelegramApi`. В тестах провайдер подменяется фейком — ни один тест не
ходит в Telegram. Чистая логика (разбор команд и callback-ов, нормализация
обновлений, токены привязки и ссылки, тексты) вынесена в отдельные модули и
покрыта unit-тестами.

# Челленджи

Челленджи — совместные испытания на несколько дней: «30 дней без доставки»,
«Неделя без импульсных покупок» и свои задания. Друзей можно позвать по коду или
из подписок, общий рейтинг показывает только никнеймы и счёт. Реализация — ТЗ §4
(пункт «Челленджи», приоритет P2). Экран живёт в `app/(app)/challenges`.

## Экран `/challenges`

- Список челленджей, шаблоны из ТЗ §4 и создание нового испытания.
- Вступление по коду и код приглашения с копированием.
- Отметка «держусь», рейтинг участников и приглашение друзей.

Клиент — `lib/challenges-client.ts` через `authFetch`. Все строки интерфейса —
в `src/lib/i18n.ts` (ru/en, одинаковые ключи).

## Шаблоны и виды

`CHALLENGE_TEMPLATES` в `@puls/shared/src/challenges.ts` — три шаблона из ТЗ §4
с видом и длительностью. Вид челленджа (`kind`): `no_spend_category`,
`streak_checkin`, `custom`. Для `streak_checkin` прогресс (дни выдержки и серия)
считается автоматически по ежедневным отметкам.

## Поля челленджа

Модель `Challenge` (ТЗ §7): `id`, `owner_id`, `title`, `kind`
(`no_spend_category` / `streak_checkin` / `custom`), `duration_days`,
`start_date`, `visibility` (`private` / `friends` / `public`), уникальный
`invite_code`.

- `ChallengeParticipant` — `challenge_id`, `user_id`, `joined_at`; пара
  `(challenge_id, user_id)` уникальна, повторное вступление идемпотентно.
- `ChallengeCheck` — `challenge_id`, `user_id`, `date`, `ok`: ежедневная отметка
  «держусь», одна на (челлендж, пользователь, день).

## Приватность

- Участник видит челлендж всегда; `private` — только участники, `friends` —
  подписчики владельца (существующий `Follow`, проверка `isFollowing`),
  `public` — все авторизованные. Чужой или невидимый идентификатор даёт `404`.
- Состав и рейтинг доступны только участникам: постороннему — `404`.
- В рейтинг и состав попадают только никнеймы, счёт (дни выдержки) и серия —
  почта, суммы и прочие приватные данные не раскрываются.
- Приглашать можно только тех, на кого ведущий сам подписан (иначе
  `not_following`); приглашение идемпотентно.

## Прогресс и рейтинг

Расчёты вынесены в чистые функции `@puls/shared/src/challenges.ts`:
`challengeEndDate` / `challengeDayNumber` / `isDayInChallenge` (окно челленджа),
`challengeHeldDays` (уникальные ok-дни внутри окна), `challengeCurrentStreak`
(текущая серия — с сегодня либо со вчера), `challengeProgressPercent` (0..100),
`challengeCheckedToday`, `challengeLeaderboard` (сортировка: дни выдержки →
серия → никнейм, места 1..N) и `canViewChallenge`.

## API

Все маршруты — под `SessionGuard` (`/api/challenges`):

| Метод | Путь | Назначение |
| --- | --- | --- |
| GET | `/` | Мои челленджи (веду и участвую) с прогрессом |
| POST | `/` | Создать челлендж (ведущий сразу участник), вернуть код |
| GET | `/:id` | Челлендж с составом и моим прогрессом (видимый зрителю) |
| PUT | `/:id` | Правка названия и видимости (ведущий) |
| DELETE | `/:id` | Удалить челлендж вместе с отметками (ведущий) |
| POST | `/join` | Вступить по коду (идемпотентно) |
| POST | `/:id/check` | Отметка «держусь» / «сорвался» на день (участник) |
| GET | `/:id/leaderboard` | Рейтинг: место, никнейм, дни выдержки, серия (участник) |
| GET | `/:id/invite-candidates` | Подписки, которых можно позвать (ведущий) |
| POST | `/:id/invite` | Позвать подписку по никнейму (ведущий) |

Ошибки — в едином формате `{ code, message }`: `validation_error`,
`unauthorized`, `challenge_not_found` (404), `challenge_forbidden` (403),
`invite_not_found` (404), `challenge_full` (409), `date_out_of_range` (400),
`invalid_start_date` / `invalid_date` (400), `user_not_found` (404),
`not_following` (403).

# Сверка со счётом банка

«Сверка» отвечает на вопрос: **почему баланс в Пульсе не равен балансу в приложении банка?**
Откройте «Финансы» → «Сверка», выберите счёт.

## Что вы увидите

- **Баланс по Пульсу** — сколько на счёте по вашим операциям.
- **Баланс по банку** — остаток после последней операции из последней загруженной выписки
  либо баланс, который вы ввели вручную.
- **Разница** — Пульс минус банк. Если 0, всё сходится.
- **Подозрительные операции** — то, из-за чего цифры расходятся.

## Как получить баланс банка

1. **Загрузите выписку** в «Импорт выписки». Если в файле есть колонка «Баланс» (Balance),
   Пульс запомнит остаток по последней операции и сравнит его с балансом счёта.
2. **Или введите баланс вручную**: на странице сверки укажите баланс из приложения банка
   и дату, на которую он показан. Операции Пульса, внесённые позже этой даты, в разницу не входят.

## Какие операции попадают в список

| Пометка | Что значит | Что делать |
| --- | --- | --- |
| Есть в выписке, нет в Пульсе | Операцию удалили или не импортировали | Загрузите выписку заново — Пульс добавит недостающее |
| Есть в Пульсе, нет в выписке | Лишняя операция, дубль или ручной ввод (помечен «ручной ввод») | Проверьте и удалите, если это ошибка |
| Разрыв в остатках выписки | В самой выписке не хватает строки: остаток не сходится с предыдущим | Скачайте выписку банка ещё раз |

Часть разницы Пульс может не объяснить — например, если при создании счёта вы указали
начальный баланс. Тогда внизу будет строка «Не объяснено найденными операциями».

## Повторный импорт безопасен

Если в выписке есть колонка **Transaction ID**, Пульс узнаёт операции именно по ней: правки описания или
повторная загрузка того же файла не создадут дублей. Без ID операции узнаются по дате, сумме
и описанию. Две одинаковые покупки в один день (например, два проезда по 24) считаются
разными операциями.

Время операции (колонка Time) и остаток после неё (Balance) тоже сохраняются.

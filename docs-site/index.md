# Пульс

> Веб-сервис, который в одном месте ведёт личные финансы, самочувствие и достижения,
> а затем превращает эти данные в статистику и советы.

**Пульс** — полностью **self-hosted** и **open-source** (AGPL-3.0-or-later). Вы
разворачиваете сервис на своём сервере (VPS, домашний сервер, Raspberry Pi) и
полностью контролируете данные: без обязательных облачных сервисов.

## Возможности

| Область | Что умеет |
| --- | --- |
| **Финансы** | Счета, транзакции, бюджеты, свои категории, быстрый ввод «обед 450», регулярные платежи, мультивалютность с курсами |
| **Самочувствие** | Чек-ины настроения, энергии, стресса и сна, дневник, стрики и достижения |
| **Цели** | Накопления с прогрессом, прогноз и вехи, напоминания о взносах |
| **Статистика** | День/неделя/месяц по финансам и настроению, тепловая карта, корреляции |
| **Рекомендации** | Инсайты по правилам; еженедельный разбор; оценка «полезно / нет» |
| **Уведомления** | Telegram и Discord, очередь с повторами, тихие часы, расписание |
| **Telegram-бот** | Чек-ины и траты из чата, привязка аккаунта по коду |
| **Профиль и соцсеть** | Публичный профиль `/@nickname`, карточки с приватностью, лента, подписки, реакции, комментарии, шаринг-картинки |
| **HTML-страница** | Своя страница в профиле (`/@nickname/page`), редактор с предпросмотром, 4 шаблона, история версий, песочница на отдельном домене |
| **Безопасность** | Cookie-сессии, CSRF, Argon2, 2FA TOTP, шифрование секретов AES-256-GCM, роли и модерация |
| **AI-помощник** | Вопросы о своих данных обычным языком по вашему API-ключу — Anthropic, OpenAI, OpenRouter или локальная модель через Ollama |
| **Семейный режим** | Общие счета и цели семьи, у каждого — приватный дневник |
| **Открытый API** | Токены, эндпоинты и вебхуки для Home Assistant, n8n и своих скриптов |
| **Привычки** | Ежедневные и еженедельные трекеры с отметками из чек-ина, серии и статистика за 7/30 дней |
| **Челленджи** | Совместные испытания с приглашением друзей и общим рейтингом |
| **Капсула времени** | Письмо себе со снимком данных, открывается через заданный срок |
| **«Год в цифрах»** | Годовая сводка по деньгам, настроению, целям и достижениям |
| **Режим «Тишина»** | Скрывает денежные суммы по всей системе (горячая клавиша Alt+Q) |
| **Голосовой чек-ин** | Диктовка заметки и итога дня; аудио не покидает браузер — на сервер идёт только текст |
| **Виджет цели** | Встраиваемый через iframe прогресс-бар публичной цели |

цели, импорт CSV, 2FA, вход через Google и Telegram, Telegram-бот, публичный
профиль и соцсеть, HTML-страница с песочницей, модерация и шаринг, AI-помощник,
семейный режим, открытый API и вебхуки, привычки, челленджи, капсула времени,
«Год в цифрах», режим «Тишина», голосовой чек-ин и виджет цели.

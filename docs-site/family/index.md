# Семейный режим

::: warning Раздел в разработке (Фаза 4)
Семейный режим реализуется в **Фазе 4** (блок D) и пока недоступен в стабильной
сборке. Ниже — планируемое поведение по требованиям ТЗ (§4). Технические детали —
по мере готовности — появятся в файле `docs/PHASE4-FAMILY.md` репозитория; на момент
написания этой страницы он ещё не создан.
:::

**Семейный режим** — это одна из возможностей, которые даёт именно self-hosted
формат: общие счета и цели семьи живут на **одном домашнем сервере**, а у каждого
участника остаётся **свой приватный дневник**. Данные не уходят к третьим лицам —
всё хранится на вашем экземпляре.

## Что даёт

- **Общие счета семьи.** Участники видят совместные счета и траты по ним.
- **Общие цели.** Семейная цель (отпуск, подарок, крупная покупка) с общим
  прогрессом и взносами участников.
- **Приватный дневник у каждого.** Чек-ины и личный дневник самочувствия остаются
  личными; в семейный контекст они не попадают без явного решения владельца.

## Режимы экземпляра

Экземпляр «Пульса» может работать в одном из режимов регистрации:

| Режим | Для кого |
| --- | --- |
| **Один пользователь** | Личный экземпляр, регистрация закрыта |
| **Семья по приглашениям** | Несколько участников присоединяются по приглашению |
| **Открытая регистрация** | Публичный экземпляр для всех желающих |

Режим задаёт администратор в админке.

## Связь с админкой

Администратор управляет режимом регистрации, участниками и общими сущностями семьи
через [админку](/admin/). Там же видны роли и служебные настройки экземпляра
(`InstanceSettings`).

::: info Приватность остаётся приоритетом
Даже в семейном режиме личные данные (дневник, личные финансы) не смешиваются с
общими автоматически. Что именно становится общим, определяет владелец данных.
:::

# Семейный режим

**Семейный режим** — это одна из возможностей, которые даёт именно self-hosted
формат: общие счета и цели семьи живут на **одном домашнем сервере**, а у каждого
участника остаётся **свой приватный дневник**. Данные не уходят к третьим лицам —
всё хранится на вашем экземпляре.

Техническое описание — `docs/PHASE4-FAMILY.md`.

## Что даёт

- **Общие счета семьи.** Участники видят совместные счета и операции по ним; у
  каждого счёта есть баланс, который пересчитывается при доходе/расходе.
- **Общие цели.** Семейная цель (отпуск, подарок, крупная покупка) с общим
  прогрессом и взносами участников — каждый взнос хранится с автором.
- **Приватный дневник у каждого.** Чек-ины, личные цели и счета остаются личными;
  семья доступа к ним не добавляет — другой участник не увидит их ни одним
  эндпоинтом.

Личные `Account`/`Goal`/`CheckIn`/`Transaction` не меняются и семье не видны.
Приватность дневника закреплена интеграционным тестом.

## Роли и правила

| Роль | Права |
| --- | --- |
| **Владелец** | Управляет составом, создаёт приглашения, удаляет семью, а также всё, что может участник |
| **Участник** | Читает и вносит по общим счетам и целям; может выйти из семьи |

- Один пользователь может состоять **только в одной семье**.
- Приглашение — одноразовый код со сроком действия; после вступления код
  помечается использованным.
- Владельца нельзя исключить, и владелец не может выйти из семьи — сначала нужно
  передать/удалить семью.
- Кросс-семейный доступ к чужому счёту или цели отвечает `404`: чужой идентификатор
  неотличим от несуществующего.

## Режимы экземпляра

Экземпляр «Пульса» может работать в одном из режимов регистрации:

| Режим | Для кого |
| --- | --- |
| **Один пользователь** | Личный экземпляр, регистрация закрыта |
| **Семья по приглашениям** | Несколько участников присоединяются по приглашению |
| **Открытая регистрация** | Публичный экземпляр для всех желающих |

Режим задаёт администратор в админке (см. [Администрирование](/admin/)).

## Экран `/family`

Создание семьи или вступление по коду; карточка семьи с участниками и ролями;
исключение участника, выход или удаление семьи; приглашение с копированием кода;
общие счета с операциями доход/расход и историей; общие цели с кольцом прогресса и
формой взноса.

## API

Все маршруты — под `SessionGuard`, префикс `/api/family`:

| Метод | Путь | Кто | Назначение |
| --- | --- | --- | --- |
| GET | `/` | участник | Моя семья с участниками (`family: null`, если семьи нет) |
| POST | `/` | любой | Создать семью (создатель — владелец) |
| DELETE | `/` | владелец | Удалить семью и все общие данные |
| POST | `/invites` | владелец | Создать одноразовый код-приглашение со сроком |
| POST | `/join` | любой | Вступить по коду |
| DELETE | `/members/:userId` | владелец | Исключить участника |
| POST | `/leave` | участник | Выйти из семьи (владелец — нет) |
| GET | `/accounts` | участник | Общие счета и суммарный баланс |
| POST | `/accounts` | участник | Создать общий счёт |
| PUT | `/accounts/:id` | участник | Правка общего счёта |
| DELETE | `/accounts/:id` | участник | Удалить общий счёт |
| GET | `/accounts/:id/transactions` | участник | История операций по счёту |
| POST | `/accounts/:id/transactions` | участник | Доход/расход (кто внёс — из сессии) |
| GET | `/goals` | участник | Общие цели с прогрессом |
| POST | `/goals` | участник | Создать общую цель |
| PUT | `/goals/:id` | участник | Правка общей цели |
| DELETE | `/goals/:id` | участник | Удалить общую цель |
| POST | `/goals/:id/deposit` | участник | Взнос участника в общую цель |

Ошибки — в едином формате `{ code, message }`: `validation_error`,
`family_not_found`, `family_forbidden` (403), `family_already_member` (409),
`family_full` (409), `family_owner_cannot_remove` / `family_owner_cannot_leave`
(409), `invite_not_found` (404), `account_not_found` / `goal_not_found` /
`member_not_found` (404), `unauthorized` (401).

## Расчёты

Чистые функции в `@puls/shared/src/family.ts`: `familyBalanceDelta` /
`applyFamilyTransaction` (доход «+», расход «−»), `isFamilyInviteActive` (код не
использован и не истёк) и `familyGoalSummary` — прогресс, остаток, нужный взнос в
месяц, прогноз даты и вехи (переиспользует расчёты целей из
[Цели](/guide/usage/goals)).

::: info Приватность остаётся приоритетом
Даже в семейном режиме личные данные (дневник, личные финансы, личные цели) не
смешиваются с общими. Что именно становится общим, определяете вы, создавая общий
счёт или цель.
:::

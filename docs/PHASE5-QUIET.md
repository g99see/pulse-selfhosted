# Фаза 5, блок J2 — режим «Тишина»

Реализация ТЗ §4 (P1, «Режим Тишина»): клиентский режим без бэкенда, который
одним жестом прячет все денежные суммы и балансы на экранах — удобно в
общественном месте.

## Состояние

- `localStorage` ключ `puls_quiet` (`'1'` — включён) и cookie `puls_quiet`
  (`SameSite=Lax`, 1 год) — запасной источник, если `localStorage` недоступен
  (приватный режим).
- На `<html>` выставляется атрибут `data-quiet="true"`, чтобы стили могли
  подстраховать рендер.
- `useQuietMode()` (в `lib/use-quiet-mode.ts`) — подписка через
  `useSyncExternalStore`: один модульный store на вкладку, переключение видно
  всем компонентам; межвкладочные изменения ловит событие `storage`.
  `setQuietMode` / `toggleQuietMode` меняют состояние, `quietModeValue()` — чтение
  без подписки.

## Компоненты

- `<Money value currency />` (`components/money.tsx`) — обёртка суммы: в тишине
  рисует маску `••••` (константа `MASKED_AMOUNT`), иначе `formatMoneyLocale`;
  скрытая сумма помечена `aria-label` и `data-quiet-masked`. Для сумм внутри
  составных строк экраны используют хук и `MASKED_AMOUNT` напрямую.
- `QuietModeToggle` — кнопка с `aria-pressed` и понятной подписью; в шапке
  `AppShell` и в секции настроек.
- `QuietModeHotkey` монтируется один раз в `AppShell`: горячая клавиша **Alt+Q** и
  вежливый `aria-live`-регион, объявляющий смену состояния скринридеру.
- `QuietModeSection` (`components/quiet-mode-section.tsx`) — блок в настройках с
  пояснением.

## Куда применено

Суммы скрываются на экранах: главная (дашборд дня `today-stats.tsx`), статистика,
финансы и регулярные платежи, цели, семья, рекомендации и «Год в цифрах».
Поля ввода (например, предпросмотр быстрого ввода) не маскируются — пользователь
видит то, что печатает.

## Доступность

- `aria-pressed` на переключателе, локализованные `aria-label` / `title`.
- Смена состояния объявляется через `role="status"` + `aria-live="polite"`.
- Горячая клавиша работает из любого места кабинета.

## Тесты

- `apps/web/e2e/quiet-mode.spec.ts` — трата видна при выключенном режиме; кнопка в
  шапке прячет сумму (`••••`) и ставит `data-quiet`; состояние переживает
  перезагрузку; на финансах суммы тоже скрыты; **Alt+Q** возвращает суммы; секция
  настроек переключает режим, после чего статистика показывает маску.

Существующие e2e не затронуты: по умолчанию режим выключен, суммы видны как раньше.

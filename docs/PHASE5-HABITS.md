# Фаза 5, блок G — привычки

Реализация ТЗ §4 (P2, «Привычки: трекер привычек (вода, спорт, чтение) с
отметками в чек-ине»): модель `Habit` и `HabitLog`, CRUD `/api/habits`,
идемпотентные отметки за дату, экран `/habits` и блок «Привычки сегодня» в
чек-ине.

## Эндпоинты (префикс `/api/habits`, все под `SessionGuard`)

| Метод | Путь | Назначение |
| --- | --- | --- |
| GET | `/` | Список привычек (активные, затем архив) |
| GET | `/:id` | Одна привычка |
| POST | `/` | Создание (название, иконка, частота) |
| PUT | `/:id` | Правка (в т.ч. архивация `archived`) |
| DELETE | `/:id` | Удаление вместе с отметками |
| POST | `/:id/log` | Идемпотентная отметка за дату (`done=false` снимает) |
| GET | `today` | Привычки текущего дня с отметкой и серией |
| GET | `stats` | Серия и проценты за 7/30 дней по каждой привычке |

Ошибки в едином формате `{ code, message }`: `validation_error`,
`habit_not_found`, `habit_future_date`, `unauthorized`.

Отметка идемпотентна: пара `(habit_id, date)` уникальна, повторный вызов за ту
же дату обновляет существующую запись, а не создаёт дубликат. Дата — календарный
день в часовом поясе пользователя (`users.timezone`), будущее отклоняется.

## Данные (ТЗ §7)

- `Habit` — `name`, `icon` (эмодзи-пресет, без загрузки файлов),
  `goal_type` (`daily` — каждый день / `weekly` — `per_week` раз в неделю),
  `per_week` (1–7), `archived`.
- `HabitLog` — `habit_id`, `user_id`, `date` (`@db.Date`), `done`.
  Уникально на `(habit_id, date)`.

Миграция — `apps/api/prisma/migrations/20261001172000_habits` (создаёт `habits`
и `habit_logs`). Таблицы добавлены в реестр выгрузки `account/data-registry.ts`.

## Чистые функции (`@puls/shared/src/habits.ts`, ТЗ §4)

- `habitStreak(doneDayKeys, todayKey)` — серия дней подряд; если сегодня ещё не
  отмечено, серия не считается прерванной до конца дня (отсчёт от вчера).
- `habitCompletionRate(doneDayKeys, todayKey, windowDays, cadence, perWeek)` —
  процент выполнения за 7/30 дней, 0..100: у `daily` ожидание — каждый день, у
  `weekly` — `per_week * windowDays / 7`.
- `habitExpectedCompletions`, `habitDayKey`, `shiftDayKey`, `habitDayToDate`,
  `habitDateToDayKey`, `habitStatsFromDayKeys`.
- Схемы `HabitCreateSchema`, `HabitUpdateSchema`, `HabitLogSchema` (Zod).

## Web

- `/habits` — форма привычки (название, иконка-пресет, частота, цель в неделю),
  список активных с серией и процентами за 7/30 дней, архив с возвратом и
  удалением. Все строки — в `src/lib/i18n.ts` (ru/en, одинаковые ключи).
- Блок «Привычки сегодня» (`components/habits-today.tsx`) с чекбоксами —
  на странице чек-ина `/checkin` и в карточке чек-ина на главной; обновляется по
  событию `puls:habits-changed`. Если привычек нет — блок не показывается.
- Пункт `Привычки` в навигации `components/app-shell.tsx`.

## Изоляция и безопасность (ТЗ §6)

Каждый запрос фильтруется по `user_id` сессии: чужая привычка не видна и не
меняется (`404`). Закреплено интеграционным тестом «Изоляция данных между
пользователями». Достижение за серию привычки намеренно не добавлялось.

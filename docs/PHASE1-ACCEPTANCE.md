# Приёмка Фазы 1 (MVP)

Проверено командами из корня репозитория:

- `pnpm lint`, `pnpm typecheck` — чисто
- `pnpm test` — shared 121, api 167 (интеграционные против PostgreSQL, схема puls_test), web 91
- `pnpm build` — shared, api, web
- `pnpm e2e` — 17 сценариев Playwright (регистрация→онбординг, быстрый ввод, чек-ин, статистика, экспорт/удаление, категории, PWA/темы/язык)
- `pnpm license:check` — все зависимости совместимы с AGPL-3.0-or-later
- Lighthouse (production-сборка): `/` Perf 97 / A11y 100, `/login` Perf 95 / A11y 100
- `docker compose up -d`: 5 контейнеров healthy, миграции применяются при старте, регистрация через https://localhost

- Нет резервного копирования по расписанию с восстановлением одной командой (ТЗ §6, §9 п.7) и мастера первого запуска.

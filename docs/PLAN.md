# План проекта «Пульс» (по ТЗ из ~/Downloads)

Стек: pnpm-монорепо; apps/web (Next.js 15), apps/api (NestJS + Prisma + PostgreSQL 16 + Valkey/BullMQ), packages/shared (Zod-схемы). Лицензия AGPL-3.0-or-later.

## Фаза 0. Окружение и каркас
- Docker + compose (нужен sudo), Postgres/Valkey через compose для dev
- Монорепо, lint/format, Vitest, Playwright, CI (GitHub Actions), LICENSE/CONTRIBUTING/SECURITY
- Проверка: `pnpm build && pnpm test` зелёные

## Фаза 1. MVP (критерии приёмки из §9) — ВЫПОЛНЕНА (пп. 1–8; не сделано: см. docs/PHASE1-ACCEPTANCE.md)
1. Auth: email+пароль (Argon2), сессии, подтверждение email (SMTP), онбординг 4 шага, никнейм
2. Финансы: счета, категории, транзакции (3 нажатия), быстрый ввод текстом, переводы, бюджеты 80/100%
3. Чек-ины: шкала 1–5, расширенный чек-ин, вечерний итог, заполнение задним числом 24 ч
4. Статистика: DailyStat + кеш, дашборд дня/недели/месяца, тепловая карта, сравнение периодов
5. Уведомления: web push (VAPID), email, тихие часы, расписание по часовому поясу
6. PWA (Serwist), светлая/тёмная тема, i18n ru/en, дизайн-система по §8
7. Экспорт JSON/CSV и удаление аккаунта; Docker Compose + Caddy + healthchecks + бэкап
8. Приёмка: e2e сценарии 1 и 2, Lighthouse ≥90 (Perf/A11y), чистая установка `docker compose up -d`

## Фаза 2 (релиз 2). Цели, регулярные платежи, импорт CSV, мультивалютность, рекомендации по правилам, стрики/достижения, 2FA TOTP, Google/Telegram вход, Telegram-бот
## Фаза 3 (релиз 3). Публичный профиль, подписки/лента/реакции/комментарии, HTML-страницы в песочнице (отдельный домен, CSP, версии), модерация, шаринг-картинка
## Фаза 4 (релиз 4). AI-помощник (адаптер провайдеров, шифрование ключей AES-256-GCM, function calling read-only, учёт токенов), семейный режим, API/вебхуки, документация VitePress

## Проверки после каждого этапа
unit (Vitest) → интеграционные (API+БД) → e2e (Playwright) → lint/typecheck → ручной прогон через браузер.

# «Пульс» — шорткат iPhone для быстрого ввода трат

Пошаговая инструкция по сборке шортката «Пульс — трата» в приложении
**Команды** (Shortcuts) на iPhone. Шорткат отправляет текст вида «кофе 250»
на `POST /api/v1/transactions/quick`, и сервер сам разбирает сумму, тип и
категорию. Запускать можно из Siri, из меню «Поделиться», иконкой на домашнем
экране или автоматизацией по транзакции Apple Pay.

Дизайн-обоснование и сравнение способов ввода — `docs/MONEY-INPUT.md`;
описание публичного API и токенов — `docs/PHASE4-API.md`.

- Эндпоинт: `POST {BASE_URL}/api/v1/transactions/quick`
- Аутентификация: заголовок `Authorization: Bearer puls_…` (scoped-токен)
- Идемпотентность: заголовок `Idempotency-Key` — свежий UUID на каждый запуск
- Формат ответа: JSON либо короткая фраза (`?format=text`)

## 1. Предпосылки

1. **Создайте токен.** В веб-приложении «Пульс» → **Настройки** →
   **«Открытый API»** → создайте токен и выберите пресет **«тPhone / Ярлыки»**
   (область `transactions:quick`). Полное значение вида `puls_…` показывается
   **ровно один раз** — сразу скопируйте его в менеджер паролей или в заметку.
2. **Узнайте базовый URL** (`BASE_URL`) — адрес, по которому сервер доступен с
   телефона **по HTTPS**. iOS Shortcuts отказывается работать с `http://`,
   поэтому варианты: домен через Caddy (`https://puls.example.com`) либо
   Tailscale Serve (`https://your-host.your-tailnet.ts.net` — сертификат валидный,
   доступ только внутри tailnet, на iPhone должен быть подключён Tailscale).
   `http://localhost:3001` с телефона не годится.
3. **Проверьте доступ** — откройте `{BASE_URL}/api/v1/me` в Safari на iPhone
   (должен ответить `401 unauthorized`, а не ошибку сертификата; это значит, что
   HTTPS рабочий).

Формат токена: `puls_` + 43 символа base64url. Токен персональный и
привязан только к быстрому вводу: читать список, удалять или менять категории
он не может.

## 2. Шорткат «Пульс — трата»

Откройте **Команды** → «+» → задайте имя **«Пульс — трата»**. Добавьте действия
в таком порядке:

**1) Ask for Input** (Запросить ввод)

- Тип ввода: **Text**, приглашение: `Что записать?`
- Можно заменить на **Dictate Text** (Продиктовать текст) — тогда при запуске
  сразу включится распознавание речи.

**2) UUID** (Универсальный уникальный идентификатор)

- Добавьте действие **UUID** — оно сгенерирует строку-идентификатор.

**3) Get Text** (Получить текст)

- Сразу под UUID добавьте **Get Text**. В качестве входа подставьте результат
  действия **UUID** (в поле ввода нажмите «Выбрать переменную» → **UUID**).
- Итог этого шага — строка UUID. Именно она пойдёт в `Idempotency-Key`, чтобы
  повторная отправка после таймаута не создала вторую трату.

**4) Get Contents of URL** (Получить содержимое URL)

- **URL:** `{BASE_URL}/api/v1/transactions/quick`
- Нажмите **Показать больше** и настройте:
  - **Method:** `POST`
  - **Request Body:** выберите **JSON**
  - Добавьте поля тела:
    | Ключ | Тип | Значение |
    | --- | --- | --- |
    | `text` | Text | результат **Ask for Input** (переменная «Provided Input») |
    | `date` | Text | результат действия **Date** → **Format Date** (`yyyy-MM-dd`) |
    | `accountId` | Text | оставьте пустым (`null`) |
    | `source` | Text | `shortcut` |
  - В разделе **Headers** добавьте два заголовка:
    | Header | Значение |
    | --- | --- |
    | `Authorization` | `Bearer puls_…` (ваш токен целиком) |
    | `Idempotency-Key` | результат действия **Get Text** (переменная из шага 3) |
  - `Content-Type` ставить вручную не нужно — JSON-тело его выставит само.

**5) Speak Text** или **Show Result**

- **Speak Text** (Проговорить текст) с результатом шага 4 — Siri вслух
  подтвердит запись.
- Либо **Show Result** (Показать результат) — короткое уведомление на экране.

## 3. Запуск через Siri

Назовите шорткат так, чтобы его удобно было произносить: **«Пульс — трата»**.
Затем: «Эй, Сири, **Пульс — трата**» — Siri спросит текст, вы диктуете
«кофе 250», и трата записывается.

**Предупреждение:** Siri иногда «съедает» первые слова или плохо распознаёт
имя шортката, если оно длинное или с дефисом. Если фраза не срабатывает —
вызовите шорткат из виджета/Siri-виджета или сократите имя до одного слова
(например, «Трата»). Проверьте 2–3 варианта произношения.

## 4. Вариант через «Поделиться» (Share Sheet)

Полезно, когда текст уже есть на экране (сообщение, чек, заметка):

1. В том же шорткате первым действием поставьте приём входа: **Shortcut Input**
   (в настройках шортката включите «Показывать в меню Поделиться» и укажите
   типы «Текст»). Вместо **Ask for Input** используйте **Get Text** от
   **Shortcut Input** — тогда текст приходит из системы.
2. Выделите текст в любом приложении (например, «кофе 250») → **Поделиться** →
   выберите **«Пульс — трата»**.
3. Шорткат сразу отправит выделенное на сервер.

Один шорткат может совмещать оба режима: если **Shortcut Input** пуст, шорткат
спрашивает текст (**Ask for Input**); если есть — использует его.

## 5. Иконка на домашнем экране

Быстрый доступ без Siri и «Поделиться»:

1. Откройте страницу шортката → **…** (меню) → **Поделиться** → **Добавить на
   экран «Домой»**.
2. Выберите иконку и имя. Теперь тап на иконку запускает шорткат в один шаг.
3. Если хочется запуска из основного приложения **Команды**, тот же шорткат
   лежит на вкладке «Мои команды».

## 6. Автоматизация Wallet / Apple Pay

**iOS 17+.** Автоматизация по транзакции срабатывает без подтверждения
(**Run Immediately**), но Apple признаёт нестабильность, поэтому это дополнение,
а не единственный канал.

1. **Команды** → **Автоматизация** → «+» → **Transaction** (Транзакция).
2. Выберите карту/мерчанта и, при желании, диапазон суммы.
3. Действие: **Run Immediately**, без «Спросить перед запуском».
4. Внутри автоматизации соберите тело запроса. Доступны переменные
   **Merchant** и **Amount**; подставьте их в `text`:
   - `text` = `Merchant` + пробел + `Amount` (например, `Кофейня 250`)
   - остальные поля — как в разделе 2.

Известные проблемы (iOS 17+): `Amount` иногда приходит пустым, триггер
срабатывает только на NFC-тап при разблокированном телефоне. Проверяйте
каждую покупку — при сбое записывайте трату вручную.

## 6b. Короткая фраза для Siri (`?format=text`)

Чтобы Siri **проговаривала** подтверждение вида «Записал: кофе 250 ₽», добавьте
к URL параметр запроса:

- **URL:** `{BASE_URL}/api/v1/transactions/quick?format=text`

Тогда тело ответа — не JSON, а одна короткая фраза на русском, и действие
**Speak Text** озвучит её напрямую, без разбора JSON. Этот же режим удобен для
**Show Result**, когда не нужны детали.

## 7. Troubleshooting

| Симптом | Причина и решение |
| --- | --- |
| «Не удалось подключиться» / ошибка SSL | Используется `http://`. iOS требует **HTTPS** — возьмите домен Caddy или Tailscale URL. |
| `401 unauthorized` | Токен неверный, отозван или просрочен. Создайте новый токен и обновите заголовок. |
| `403 insufficient_scope` | У токена нет области `transactions:quick`. Пересоздайте токен с пресетом **«тPhone / Ярлыки»**. |
| `429 rate_limited` | Превышен лимит **120 запросов/мин** на токен. Подождите и повторите (в ответе есть `retryAfterSeconds`). |
| `validation_error` | Пустой или неразборчивый `text`; проверьте, что переменная **Ask for Input** действительно подставлена в тело. |
| Трата записалась, но Siri молчит | Проверьте, что в **Speak Text** подставлен результат шага 4, а не переменная UUID. |
| Повторная отправка вернула `duplicate: true` | Это **норма**: сервер увидел тот же `Idempotency-Key` и не создал вторую трату. Убедитесь, что UUID генерируется заново при каждом запуске. |
| Нужно отозвать токен | Настройки → «Открытый API» → отозвать токен, затем создать новый и заменить значение в заголовке `Authorization`. |

## 8. Проверка с компьютера (curl)

Тот же запрос, что делает шорткат, можно воспроизвести в терминале — удобно для
диагностики. `Idempotency-Key` — свежий UUID:

```bash
BASE_URL=https://your-host.your-tailnet.ts.net
TOKEN=puls_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx

curl -s -X POST \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -H "Idempotency-Key: $(uuidgen)" \
  -d '{"text":"кофе 250","date":"2026-10-13","accountId":null,"source":"shortcut"}' \
  "$BASE_URL/api/v1/transactions/quick"
```

Ответ:

```json
{ "id": "clx…", "type": "expense", "amount": 250, "categoryName": "Еда", "currency": "RUB", "duplicate": false }
```

Повторный запуск **с тем же** `Idempotency-Key` вернёт `"duplicate": true` и
не изменит баланс. Вариант с короткой фразой:

```bash
curl -s -X POST \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -H "Idempotency-Key: $(uuidgen)" \
  -d '{"text":"кофе 250","date":"2026-10-13","accountId":null,"source":"shortcut"}' \
  "$BASE_URL/api/v1/transactions/quick?format=text"
```

Вывод: `Записал: кофе 250 ₽`.

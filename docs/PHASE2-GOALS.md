# Фаза 2 — цели накоплений

Реализация ТЗ §3.2 (пункт «цели накоплений») и §5 (сценарий 2): модель цели,
CRUD, пополнения, расчёт взноса в месяц и прогноз даты достижения, вехи
25/50/75/100% и экран `/goals` с карточкой на главной.

## Эндпоинты (префикс `/api/goals`, все под `SessionGuard`)

| Метод | Путь | Назначение |
| --- | --- | --- |
| GET | `/` | Список целей пользователя с прогрессом |
| GET | `/:id` | Одна цель |
| POST | `/` | Создание цели (сумма, срок, картинка, приватность, счёт) |
| PUT | `/:id` | Правка цели |
| DELETE | `/:id` | Удаление цели |
| POST | `/:id/deposit` | Пополнение цели |

Ошибки в едином формате `{ code, message }`: `validation_error`,
`goal_not_found`, `account_not_found`, `unauthorized`.

Ответ пополнения содержит событие вехи:

```json
{
  "goal": { "savedAmount": 60000, "percent": 50, "milestones": [25, 50], "...": "..." },
  "deposit": { "amount": 60000, "date": "2026-10-01T00:00:00.000Z" },
  "milestone": { "percent": 50, "reached": [25, 50] }
}
```

`milestone.reached` — только вехи, пересечённые **этим** пополнением; подписку
на достижения делает модуль достижений (другой агент), здесь событие только
отдаётся в ответе API.

## Данные (ТЗ §7)

- `Goal` — `title`, `target_amount`, `saved_amount`, `deadline`, `image`
  (эмодзи-пресет или URL, без загрузки файлов), `visibility`
  (`public` / `subscribers` / `private`), необязательный `account_id`
  (счёт-сбережения), `currency`. Суммы — `Decimal(14,2)`.
- `GoalDeposit` — история пополнений цели (`goal_id`, `user_id`, `amount`,
  `date`, необязательный `account_id`). История даёт фактический темп для
  прогноза даты достижения.

Миграция — `apps/api/prisma/migrations/20261001155422_goals` (создаёт `goals` и
`goal_deposits`). Пополнение со счёта списывает сумму со счёта в одной
транзакции БД с записью пополнения и ростом `saved_amount`.

## Чистые функции (`@puls/shared/src/goals.ts`, ТЗ §3.2)

- `goalProgress(saved, target)` — прогресс в %, 0..100, не делит на ноль.
- `requiredMonthlyContribution(target, saved, deadline, from)` — нужный взнос в
  месяц: «120 000 ₽ к 1 марта → 24 000 ₽/мес» (`null`, если срок не задан; `0`,
  если цель достигнута).
- `goalPacePerMonth(deposits, from)` и `forecastGoalDate(saved, target, pace,
  from)` — прогноз даты достижения по фактическому темпу.
- `reachedMilestones(percent)` / `crossedMilestones(previous, next)` — вехи
  25/50/75/100%.

## Web

- `/goals` — кольцо прогресса (SVG, ТЗ §8), форма цели (название, сумма, срок,
  эмодзи-пресет или ссылка, приватность, необязательный счёт-сбережения) и форма
  пополнения с показом новой вехи.
- Карточка `GoalsCard` на главной `/app` — кольца прогресса до двух целей и
  ссылка на `/goals`; обновляется по событию `puls:goals-changed`.
- Все строки интерфейса — в `src/lib/i18n.ts` (ru/en, одинаковые ключи).

## Изоляция и безопасность (ТЗ §6)

Каждый запрос фильтруется по `user_id` сессии: чужая цель не видна и не
меняется (`404`), пополнение с чужого счёта отклоняется (`404`). Закреплено
интеграционным тестом «Изоляция данных между пользователями».

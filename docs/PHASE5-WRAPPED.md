# Фаза 5, блок J1 — «Год в цифрах»

Реализация ТЗ §3.4: сводка за календарный год по личным данным пользователя —
сколько потрачено и заработано, топ категорий, самый дорогой день, частый день
недели, настроение по месяцам, лучший и худший месяц, самый длинный стрик
чек-инов, число завершённых целей и полученных достижений.

Изменений схемы БД нет: фича читает существующие таблицы.

## Эндпоинт

| Метод | Путь | Кто | Назначение |
| --- | --- | --- | --- |
| GET | `/api/wrapped` | владелец сессии (`SessionGuard`) | Сводка за год; параметр `year` необязателен |

Параметр `year` (1970…9999) необязателен: без него берётся текущий год в
часовом поясе пользователя (как и везде — по `todayKeyInTimezone`). Некорректный
год → `400 { code: 'validation_error', message: 'Некорректный год' }`. Без сессии
— `401 unauthorized`.

## Таблицы-источники

| Данные | Таблица | Условие выборки |
| --- | --- | --- |
| Траты и доходы | `transactions` | `type in (expense, income)`, `date` в пределах года |
| Названия категорий | `categories` | по `categoryId` транзакций |
| Настроение | `check_ins` | `occurredAt` в границах года по часовому поясу |
| Завершённые цели | `goals` | `savedAmount >= targetAmount` и `updatedAt` в году |
| Достижения | `user_achievements` | `earnedAt` в году |

Переводы (`type = 'transfer'`) в расходы и доходы не попадают. Границы года для
денег — по дате `@db.Date` (UTC-полночь), для чек-инов — по локальному поясу
пользователя через `zonedDayBounds`.

Завершение цели приближено моментом последнего обновления (`updatedAt`): точной
даты закрытия модель `Goal` не хранит — это отмечено комментарием в сервисе.

## Чистые функции (`@puls/shared/src/wrapped.ts`, ТЗ §3.4)

- `topCategories(transactions, limit = 3)` — только расходы; группировка по
  `categoryId` (без категории — отдельный ключ), сортировка по сумме убыванию,
  затем по имени; суммы округляет `roundMoney`.
- `mostExpensiveDay(transactions)` — день с максимальной суммой расходов; при
  равенстве — ранний; без расходов — `null`.
- `mostFrequentWeekday(transactions)` — частый день недели по числу расходных
  транзакций (`getUTCDay`, 1=Пн … 7=Вс); при равенстве — меньший; без расходов —
  `null`.
- `moodByMonth(checkins)` — среднее настроение по месяцам (один знак), по
  возрастанию ключа `YYYY-MM`.
- `bestWorstMoodMonths(months)` — лучший/худший месяц по среднему; при равенстве
  — ранний; пусто → `{ best: null, worst: null }`.
- `bestStreakOf(checkins)` — самый длинный стрик по уникальным дням
  (`computeStreak` из `achievements`).
- `buildWrapped(input, { timezone, currency })` — сборка ответа: переиспользует
  `sumSpent` / `sumEarned` / `roundMoney` из `stats` и `moodAverage` из `mood`.

## Пустой год

Если данных за выбранный год нет, ответ — нули и `null`: `spent`/`earned`/`net`
= 0, `topCategories` = `[]`, `mostExpensiveDay`/`mostFrequentWeekday` = `null`,
`avgMood`/`bestMonth`/`worstMonth` = `null`, остальные счётчики = 0. Это
проверено и unit-, и интеграционным тестом.

## API

- `apps/api/src/wrapped/wrapped.service.ts` — `WrappedService.year(userId, year?)`:
  читает пользователя (пояс, валюта), транзакции года с названиями категорий,
  чек-ины в границах года, считает завершённые цели и достижения, отдаёт
  `buildWrapped(...)`.
- `apps/api/src/wrapped/wrapped.controller.ts` — `GET /wrapped` под `SessionGuard`,
  разбор `WrappedQuerySchema`.
- `apps/api/src/wrapped/wrapped.module.ts` — `imports: [AuthModule]`.
- `apps/api/src/app.module.ts` — модуль добавлен в `imports[]`.

## Web

- `/wrapped` — экран-«сторис» (ТЗ §4): слайды обложка → деньги → топ категорий →
  дни года → настроение → чек-ины → цели и достижения → «Поделиться». Листается
  кнопками и стрелками клавиатуры (`←`/`→`), каждый слайд размечен
  `aria-roledescription` и подписью «Слайд N из M», смена слайда анимируется и
  отключается при `prefers-reduced-motion`. Флаг `isEmpty` показывает отдельный
  слайд «Пока пусто». Год переключается кнопками «Раньше/Позже» (не дальше
  текущего).
- `lib/wrapped-client.ts` — клиент `wrappedApi.year(year?)` через `authFetch`.
- Ссылки без пункта навигации: баннер на главной (`app/(app)/app/page.tsx`)
  виден с 1 декабря по 31 января, постоянная ссылка — на экране «Статистика»
  (`data-testid="stats-wrapped-link"`).
- «Поделиться» — Web Share API с текстовым итогом года, при отсутствии — копия в
  буфер обмена (существующий карточный share-механизм не расширялся, чтобы не
  менять контракт `share-card`).
- Все строки — в `src/lib/i18n.ts` (ru/en).
- `apps/web/e2e/wrapped.spec.ts` — переход со статистики, листание кнопками и
  стрелками, сумма траты на слайде денег.

Режим «Тишина» тоже применяется к суммам на экране «Год в цифрах» — см.
`docs/PHASE5-QUIET.md`.

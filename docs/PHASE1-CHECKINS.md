# Фаза 1.3 — чек-ины самочувствия

Реализация ТЗ §3.3, §5 (сценарий 1), §7 (`CheckIn`) и §8: ответ настроением за
5 секунд, расширенный чек-ин, вечерний итог дня, заполнение задним числом и
расписание напоминаний.

## Эндпоинты (префикс `/api/checkins`, все под `SessionGuard`)

| Метод | Путь | Назначение |
| --- | --- | --- |
| GET | `/` | Список чек-инов за период (`?from&to&limit`) |
| GET | `/today` | Чек-ины текущего дня по часовому поясу пользователя |
| GET | `/schedule` | Расписание напоминаний (1–6 раз в день) |
| POST | `/` | Чек-ин: настроение + расширенные поля, `occurredAt` необязателен |
| POST | `/quick` | Ответ за 5 секунд: только настроение (и провал дня) |
| GET | `/:id` | Один чек-ин (чужой → 404) |
| PUT | `/schedule` | Сохранить расписание |
| PUT | `/:id` | Правка своего чек-ина (например, дописать итог дня) |
| DELETE | `/:id` | Удаление своего чек-ина |

Ошибки в едином формате `{ code, message }`: `validation_error`,
`checkin_window_expired`, `checkin_not_found`, `unauthorized`.

## Данные (ТЗ §7, миграция `20261001125709_checkins`)

`CheckIn` расширен полями:

- `water` — стаканы воды, `steps` — шаги;
- `day_summary` — вечерний итог дня, одна строка (ТЗ §3.3);
- `slot` — провал дня `morning` / `day` / `evening`;
- `occurred_at` — фактический момент чек-ина (для заполнения задним числом),
  индекс `(user_id, occurred_at)`.

У `User` появились `checkin_times_per_day` (по умолчанию 3) и `checkin_times`
(`['09:00','15:00','21:00']`) — хранение расписания.

## Правила

- **Настроение** — целое 1–5; энергия и стресс тоже 1–5; сон 0–24 ч; вода
  0–50; шаги 0–200 000; теги до 20 штук; заметка до 2000 символов.
- **Вечерний итог** — поле `daySummary` до 280 символов, добавляется в чек-ин
  (создание или `PUT /:id`).
- **Задним числом** — окно 24 часа от `occurredAt`. Старше — `400`
  `checkin_window_expired`, время в будущем — `400` `validation_error`.
- **Расписание** — 1–6 напоминаний, времена в формате HH:MM без повторов;
  хранение и выдача, рассылка — за разделом уведомлений (пункт 5).
- **«Сегодня»** вычисляется по часовому поясу пользователя (`dayBoundsInTimeZone`).

## Web

- Карточка чек-ина на главной `/app`: вопрос «Как ты себя чувствуешь?», шкала
  1–5 эмодзи-кнопками и ссылка на страницу — ответ в одно нажатие.
- `/checkin`: шкала настроения, расширенный чек-ин (энергия, стресс, сон, вода,
  шаги, теги, заметка), поле «Что сегодня получилось?», история и расписание.
- Шкала настроения — цвета из ТЗ §8: `#7C8DB5` → `#D8D3CB` → `#F5C542`,
  красный не используется. Цвета и эмодзи — `@puls/shared` (`MOOD_COLORS`,
  `MOOD_EMOJI`).
- Все строки интерфейса — в `src/lib/i18n.ts` (ru/en).

## Изоляция и безопасность (ТЗ §6)

Каждый запрос фильтруется по `user_id` текущей сессии; чужой чек-ин не виден и
не редактируется (`404`). Это закреплено интеграционным тестом «Изоляция
данных».

## Тесты

```bash
pnpm --filter @puls/shared test    # чек-ины и расписание: 14 тестов (17 с mood)
pnpm --filter @puls/api test       # 23 теста чек-инов (19 интеграционных + 4 юнит)
pnpm --filter @puls/web test       # 51 юнит-тест (3 про чек-ины)
pnpm e2e                           # Playwright: чек-ин за пару кликов с главной
```

Интеграционные тесты идут в схему `puls_test`; миграции накатываются
автоматически (`globalSetup`).

# Редизайн web-интерфейса «Пульса» (октябрь 2026)

Решение владельца: направление **«мягкий wellbeing»**, объём — весь web, без изменений API и бизнес-логики.

## Направление
- Пастельные цвета областей: деньги — зелёный (`finance`), самочувствие — оранжевый/персиковый (`wellbeing`), бренд — мягкий индиго (`primary`). У каждой области есть заливка `*-soft` для фона плиток и бейджей.
- Скруглённые формы: карточки 24px, кнопки и поля 14px, чипы — пилюли. Тени мягкие и широкие в светлой теме, тонкие обводки в тёмной.
- Тёплый кремовый фон, белые поверхности, крупные заголовки Manrope.
- Пустые состояния — иллюстрация (inline SVG) + одна фраза + действие.
- Контраст WCAG AA обязателен: все текстовые пары ≥ 4.5:1 (тест `contrast.test.ts`).

## Каркас
- Десктоп: сайдбар 248px с логотипом, группами («Сегодня», «Деньги», «Самочувствие», «Сообщество», «Аккаунт»), подсветкой активного раздела (`aria-current` по текущему пути) и кнопкой «Добавить» над группами.
- Мобильный: нижняя панель из 5 элементов — Главная, Финансы, «＋», Чек-ин, «Ещё». «Ещё» открывает лист со всеми разделами.
- Шапка: приветствие, никнейм, «Тишина» (SVG-иконка глаза), выход.

## Исправляемые проблемы
1. Мобильная навигация: 16 пунктов в одной строке, видны 4.
2. `aria-current="page"` всегда на `/app`.
3. Тексты разработки на виду: «Фаза 0 пройдена» и адрес API на лендинге, «Финансы и чек-ины появятся в следующих шагах Фазы 1» на главной.
4. Иконка «Тишины» (`👁`) рисуется пустым квадратом без emoji-шрифта.
5. «Финансы» и «Чек-ины» — бесконечные ленты (150+ записей) с формами вперемешку: вкладки/разделы и постраничный показ.
6. Статистика: у графика трат нет подписей дней; дни без чек-ина в календаре настроения залиты тёмно-серым и выглядят как данные.

Проверено и не является ошибкой: `Cannot read properties of undefined (reading 'waiting')` появляется только в браузере с заблокированными сервис-воркерами (Playwright `serviceWorkers: 'block'`); в обычном браузере воркер активируется без ошибок.

## Не меняется
API, схемы shared, маршруты, `data-testid`, тексты, на которые опираются e2e. Новые строки — только через `i18n.ts` (ru + en).

## Проверка
`pnpm -r typecheck`, `pnpm --filter @puls/web test`, `pnpm --filter @puls/web build`, e2e, скриншоты light/dark/mobile до и после, Lighthouse ≥ 90.

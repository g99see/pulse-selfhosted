# Пульс v2 — редизайн «пульс-монитор» (ТЗ §6)

Продолжение [REDESIGN.md](REDESIGN.md). Прошлое направление («мягкий wellbeing»: пастельный индиго, кремовый фон, одинаковые карточки на 24px) читалось как типовой шаблон-дашборд. v2 даёт приложению собственный характер.

## 2. Направление: «пульс-монитор»

**Идея.** Приложение — тёплый кардиограф для денег и самочувствия. Один яркий «монитор» на экране (сумма трат за сегодня на глубоком бирюзовом фоне с линией пульса), всё остальное — спокойная бумага в мятную точечную «миллиметровку».

- **Палитра.** Глубокий бирюзовый `#0d5c55` (бренд, монитор), лайм (деньги), янтарь (самочувствие), коралл (предупреждение), фон — холодная мятная бумага `#e9f0ea`. Тёмная тема — «ночной монитор»: `#091210`, мятный неон `#5fe3c9`. Отказ от индиго + крема: это самый частый «дефолт».
- **Типографика.** Unbounded — широкий геометрический шрифт для h1, названия и крупных чисел (голос бренда). Onest — рабочий шрифт для текста и подзаголовков, отлично читается на кириллице. Оба variable, self-hosted (`pnpm fonts:sync`).
- **Форма.** Подпись: у каждого блока «срезан» левый нижний угол (`24px 24px 24px 8px`) — как зубец ленты. Плоская «наклейка»-тень (смещённая обводка, без размытия), 1.5px рамки у полей.
- **Иконки.** Те же линейные SVG, логотип со срезанным углом.
- **Движение.** Одно самостоятельное: линия пульса на мониторе «рисуется» при открытии главной. Остальное — отклик на действие: кнопки-«клавиши» вдавливаются (`.puls-key`), настроение «подпрыгивает». Всё отключается при `prefers-reduced-motion`.
- **Принцип.** Смелость в одном месте — монитор трат. Остальное тихое.

Использованные ориентиры: плагин `frontend-design` (см. §6).

Контраст всех текстовых пар (включая `ink-muted` на мягких заливках) и границ полей проверяет `apps/web/test/contrast.test.ts`; значения в CSS синхронны с `lib/palette.ts`.

Фокус: `outline: 3px solid var(--puls-focus)` с отступом 2px у всех интерактивных элементов. Зоны нажатия: глобальный `min-height: 44px` для button/select/summary/input, плюс `min-h-11` у ссылок-действий.

## 4. Компоненты

`Card` (срезанный угол), `Field`/`Select` (рамка 1.5px), `PrimaryButton` («клавиша»), `GhostButton`, `Alert`, `ProgressBar`, `Badge`, `IconBubble`, `StatTile` (числа Unbounded), **`MonitorTile`** (новый: бирюзовый монитор с линией пульса), `EmptyState`, `Segmented` (min 44px), `MoodScale` (кнопки ≥ 44px), нижняя панель (на всю ширину, «+» приподнят, `puls-key`), боковое меню (активный пункт — левая планка), `QuickAddSheet`, `Logo`.

## 5. Сценарии: действий с главной

Действие = касание/ввод/отправка.

| Сценарий            | Было                                                          | Стало                                                                                  |
| ------------------- | ------------------------------------------------------------- | -------------------------------------------------------------------------------------- |
| Чек-ин              | 1 (касание лица на карточке)                                  | **1** — карточка первая на экране, лица ≥ 44px                                         |
| Добавить трату      | 3 («+» → «кофе 250» → «Добавить»), «+» только в нижней панели | **3** («+» → «кофе 250» → «Добавить»); «+» теперь есть и на мониторе трат, и в панели, и в боковом меню |
| Сегодняшние итоги   | 0 (на главной), но монитор не выделялся среди карточек        | **0** — главное число дня на мониторе в первом экране                                  |

Все три ≤ 3. Событие `puls:quick-add` позволяет открывать шторку с любого экрана.

## 6. Дизайн-скилл `frontend-design`

Найден в `~/.claude/plugins/marketplaces/claude-plugins-official/plugins/frontend-design/skills/frontend-design/SKILL.md` и прочитан; его принципы (осознанный выбор шрифтов, отказ от шаблонных «кремовый + терракота», одинаковых карточек, ALL-CAPS эксиверов; смелость в одном месте; движение только как отклик) учтены выше (убраны капс-заголовки групп меню, одинаковые тени, один акцентный «монитор»).

Установка для Claude Code (глобально, мы её не запускали):

```bash
claude plugin install frontend-design@claude-plugins-official
```

Если маркетплейс не подключён: `claude plugin marketplace add anthropics/claude-plugins-official`, затем команда выше. Локально плагин лежит в `~/.claude/plugins/marketplaces/claude-plugins-official/plugins/frontend-design`.

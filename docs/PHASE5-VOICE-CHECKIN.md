# Фаза 5, блок K — Голосовой чек-ин (ТЗ §4, P2)

«Надиктовать, как прошёл день; сервис расшифрует и выделит теги». Распознавание
речи идёт **целиком в браузере** через Web Speech API
(`SpeechRecognition` / `webkitSpeechRecognition`), язык — по локали интерфейса
(`ru-RU` / `en-US`). **Аудио на сервер не уходит** — наружу летит только готовый
текст, сохранённый в поле заметки/итога дня. Это принципиально для self-hosted и
приватности: сервер не получает ни записи, ни потоковой расшифровки, ни ключей
внешних распознавателей.

## Контракт и чистая логика

| Файл | Что |
| --- | --- |
| `packages/shared/src/voice-tags.ts` | Словарь «ключевое слово → тег» (ru/en) и `extractVoiceTags(text)` |
| `packages/shared/test/voice-tags.test.ts` | Unit-тесты словаря и извлечения |
| `apps/web/src/components/voice-input-button.tsx` | Кнопка микрофона (клиентский компонент) |
| `apps/web/src/app/(app)/checkin/page.tsx` | Кнопки у заметки и итога дня, чипы предложенных тегов |

### `extractVoiceTags(text)`

- Возвращает **уникальные канонические теги в порядке словаря**; теги совпадают с
  привычными тегам чек-инов: `работа`, `спорт`, `сон`, `еда`, `семья`, `друзья`,
  `учёба`, `здоровье`, `болею`, `ссора`.
- Ключевое слово ищется **с начала слова** (`(?<![\p{L}\p{N}])`), поэтому основа
  `тренир` ловит «тренировка»/«тренируюсь», а «сон» не срабатывает на «персон».
  Регистр и «ё/е» нормализуются.
- Схему чек-ина это не меняет: тег остаётся свободной строкой до 64 символов
  (`CheckInInputSchema.tags`). Новых таблиц и миграций нет.

## Поведение интерфейса

- Кнопка микрофона появляется у **заметки** и у **итога дня** («Что сегодня
  получилось?») в расширенном чек-ине.
- Распознанный текст дописывается в соответствующее поле (заметка или итог дня).
- Найденные теги показываются **чипами в отдельном блоке** «Теги из записи»; тег
  добавляется в чек-ин только после нажатия пользователем (`aria-pressed`), то
  есть **подтверждается вручную**.
- Если Web Speech API нет, кнопка **не отображается**, а на её месте — подсказка
  с пояснением про приватность (`checkin.voice.unsupported`, ru/en).
